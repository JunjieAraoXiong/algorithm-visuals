Find the Insertion Index · 搜索插入位置

Given a sorted array of unique values and an integer target, return the target's index if it exists; otherwise return the insertion index — the index where target would sit to keep the array sorted.给定一个元素互不相同的升序数组和一个整数 target：若数组中存在 target，返回它的下标；否则返回插入位置——把 target 放进去后数组仍然有序的那个下标。

完整 Python 代码

def find_the_insertion_index(nums: List[int], target: int) -> int:    left, right = 0, len(nums)    while left < right:        mid = (left + right) // 2        # If the midpoint value is greater than or equal to the target,        # the lower bound is either at the midpoint, or to its left.        if nums[mid] >= target:            right = mid        # The midpoint value is less than the target, indicating the        # lower bound is somewhere to the right.        else:            left = mid + 1    return left

二分查找只移动 left / right / mid 三个变量，从不写入 nums 数组。

一个条件统一两种情况 · One condition covers both cases

目标在数组里 → 返回它的下标；目标不在 → 返回第一个比它大的值的下标。两种情况可以合并成一句话：第一个满足 nums[i] >= target 的下标。因为 nums 升序，这个判定的结果数组总是先 False 后 True，所以答案是 True 区的下界（lower bound）——可以用二分查找来定位。

搜索空间取 [0, n] 而不是 [0, n - 1]：若 target 比所有元素都大，插入位置是 n，答案可能落在最后一个元素之后。初始 left, right = 0, len(nums)。

区间如何收缩 · How the range shrinks

每轮取中点 mid，按判定结果把搜索区间砍成一半。不变量：下界始终在 [left, right] 之内。

nums[mid] >= target

中点已满足条件，下界只可能是 mid 或它左边。保留 mid，向左收：right = mid。

nums[mid] < target

中点太小，下界一定在 mid 右边。排除 mid，向右收：left = mid + 1。

  1. 每次收缩都把不可能的一半丢掉，区间长度大致减半，所以只需 O(log n) 轮。
  2. 当 left == right 时区间只剩一个候选，它就是第一个 True 的下标；返回 left。

边界情况 · Edge cases

target 比所有元素小

例：nums = [1, 2, 4, 5, 7, 8, 9]，target = 0。第一个 True 在下标 0，直接返回 0。

target 比所有元素大

例：target = 10。所有判定都是 False，left 一路右移，最终返回 n = 7。

target 恰好等于某个元素

例：target = 4。第一个 True 正好落在它身上，返回它的下标 2——等于的情况同样满足 >=。

空数组

nums = [] 时 left == right == 0，循环不执行，返回 0，即唯一的插入位置。

复杂度 · Complexity

时间 · O(log n)

在大小为 n + 1 的搜索空间 [0, n] 上做二分，每轮区间减半。

额外空间 · O(1)

只保存 left、right、mid 三个变量，数组不被修改。
