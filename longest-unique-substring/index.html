Longest Substring With Unique Characters · 无重复字符的最长子串

Find the longest contiguous substring with no repeated character. Expand while the window is valid; when a duplicate is inside it, move left far enough to remove that duplicate.寻找不含重复字符的最长连续子串。窗口有效时扩展；若重复字符位于窗口内，就移动 left 将它排除。

Final Python / 最终代码 

def longest_substring_with_unique_chars(s: str) -> int:    max_len = 0    hash_set = set()    left = right = 0    while right < len(s):        # Shrink until s[right] is no longer a duplicate.        while s[right] in hash_set:            hash_set.remove(s[left])            left += 1        max_len = max(max_len, right - left + 1)        hash_set.add(s[right])        right += 1    return max_len
def longest_substring_with_unique_chars_optimized(s: str) -> int:    max_len = 0    prev_indexes = {}    left = right = 0    while right < len(s):        if (s[right] in prev_indexes                and prev_indexes[s[right]] >= left):            left = prev_indexes[s[right]] + 1        max_len = max(max_len, right - left + 1)        prev_indexes[s[right]] = right        right += 1    return max_len

Shrink repeatedly or jump once / 逐步收缩，还是一次跳跃

At the second b in abcba, the earlier b is at index 1. The set version removes a, then b; the optimized version moves left directly to index 2. / 遇到第二个 b 时，旧 b 位于下标 1。集合版移除 a 再移除 b；优化版直接把 left 移到 2。

Hash set / 集合

abcb→left: 0 → 1 → 2

Previous index / 上次下标

abcb→left = 1 + 1

A previous occurrence matters only inside the window / 只有窗口内的旧位置才算重复

prev_indexes['b'] = 1 ≥ left = 0

The old b is inside → jump past it. / 旧 b 在窗口内，需要跳过。

prev_indexes['a'] = 0 < left = 2

The old a is already outside → keep left. / 旧 a 已在窗口外，不移动 left。

Solving steps / 解题步骤

  1. Use [left, right] as the current candidate substring.
  2. Keep exactly the characters, or last indexes, needed to decide whether s[right] duplicates something inside the window.
  3. Shrink or jump until the window is unique again.
  4. Update max_len, record s[right], then advance right.

Complexity / 复杂度

Time / 时间 · O(n)

Each boundary only moves forward. The optimized version may skip several individual removals. / 两个边界只向前；优化版可以跳过多次逐项移除。

Extra space / 额外空间 · O(m)

m is the number of distinct characters stored. / m 是保存的不同字符数。
