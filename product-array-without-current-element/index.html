Product Array Without Current Element · 除自身以外数组的乘积

Given an array of integers, return an array res so that res[i] is the product of all elements of the input except nums[i] itself — without using division.给定整数数组 nums，返回数组 res：res[i] 等于除 nums[i] 以外所有元素的乘积，并且不能用除法。

不变量 / Invariant

i
right_product
res

完整 Python 代码

def product_array_without_current_element(nums: List[int]) -> List[int]:    n = len(nums)    res = [1] * n    # Populate the output with the running left product.    for i in range(1, n):        res[i] = res[i - 1] * nums[i - 1]    # Multiply the output with the running right product, from right to    # left.    right_product = 1    for i in range(n - 1, -1, -1):        res[i] *= right_product        right_product *= nums[i]    return res

res 兼任输出数组与工作数组：第一遍存左积，第二遍原地乘入右积，不建 left_products / right_products。

直觉：总乘积 120，再逐个相除 / Total product, then divide

最直白的做法：先求所有数的总乘积，再分别除以每个元素。对 nums = [2, 3, 1, 4, 5]，总乘积 2·3·1·4·5 = 120，于是 res = [120/2, 120/3, 120/1, 120/4, 120/5] = [60, 40, 120, 30, 24]。每个元素的弧线都把它的值汇入同一个“总乘积”。

这是 O(n) 时间、O(1) 空间的做法——但面试官的经典追问是：如果不能用除法呢？（而且 nums 含 0 时除法直接失效。）下面的方法不依赖除法。

关键洞察：res[i] = 左积 × 右积 / Left product × right product

“除自身以外”可以拆成两段互不重叠的数：它左边的全部 × 它右边的全部。以下标 2（值 1）为例：左边 2×3 = 6，右边 4×5 = 20，两段各自累乘后再相乘，res[2] = 6 × 20 = 120——nums[2] 自己永远不在任何一段里。

前缀积：左右乘积各存一行 / Prefix products

两个数组都可以“边走边乘”得到：left_products 从左到右累乘（left_products[i] = i 左边所有数的乘积），right_products 从右到左同理。这就是前缀积——和前缀和一样，只是把累加换成累乘，初值从 0 改成 1（乘 0 会把所有累积结果清零）。逐列相乘即得答案。

逐列读：left_products[i] * right_products[i] = res[i]。以第 3 列（下标 2）为例：6 * 20 = 120。

省空间：res 原地装下两遍扫描 / Reducing space

其实不必真的建 left_products 和 right_products 两个数组。第一步把 res 当作左积数组从左到右填好；第二步不建右积数组，只用一个变量 right_product 从右往左把“右侧乘积”直接乘进 res。输出数组本身兼任工作数组，额外空间只有 O(1)。上方动画演示的就是这两遍。

第一步完成后 res = [1, 2, 6, 6, 24]，箭头表示它已就位、等待从右往左乘入 right_product；浅灰的 left_products 行只是对照，不再需要真的存储。

边界情况 / Edge cases

nums 含 0 · zeros in nums

除法方案遇到 nums[i] = 0 直接失效；左积 × 右积不受影响——0 只会让它自己的位置变成非零、其余位置为 0。如 [2, 0, 4] → [0, 8, 0]。

n = 1 · single element

两个循环都不执行，返回 [1]：唯一的元素左边、右边都没有数，空乘积按乘法单位元 1 计。

为什么用 1 初始化 · seed with 1

前缀积从 1 起步而不是 0：任何数乘 0 都会塌成 0，累乘就失去意义。res = [1] * n 让这个初值天然就位。

不能用除法 · no division

面试官的跟进追问。左积 × 右积的方案全程只有乘法，天然满足这个约束。

复杂度 / Complexity

Time · O(n)

对 nums 遍历两次：一次从左到右填左积，一次从右到左乘入右积。时间复杂度 O(n)：数组被迭代两遍（two passes）。

Extra space · O(1)

除输出数组外只用一个变量 right_product。空间复杂度 O(1)——按书上约定，res 数组不计入空间分析。
