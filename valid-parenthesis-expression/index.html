Valid Parenthesis Expression · 有效的括号

Given a string containing only '(', ')', '[', ']', '{', '}', determine whether it forms a valid parenthesis sequence: every opening parenthesis must be closed by a parenthesis of the same type, and no closing parenthesis may appear before its matching opening one.给定一个只含小中大三种括号的字符串，判断它是否为有效的括号序列：每个开括号必须由同类型的闭括号闭合，且闭括号不能出现在与它匹配的开括号之前。

完整 Python 代码

def valid_parenthesis_expression(s: str) -> bool:    parentheses_map = {'(': ')', '{': '}', '[': ']'}    stack = []    for c in s:        # If the current character is an opening parenthesis, push it        # onto the stack.        if c in parentheses_map:            stack.append(c)        # If the current character is a closing parenthesis, check if        # it closes the opening parenthesis at the top of the stack.        else:            if stack and parentheses_map[stack[-1]] == c:                stack.pop()            else:                return False     # If the stack is empty, all opening parentheses were successfully    # closed.    return not stack

parentheses_map 的 key 是开括号：一个字符在不在 map 里，就区分了它是开括号还是闭括号。

直觉：为什么用栈 / Why a stack

只统计每种括号的个数无法判断有效性，还必须检查闭合的顺序。关键观察是：读到闭括号时，它只能闭合「最近一个还没闭合的开括号」——先进入的括号要等后进入的闭合之后才有机会，这正是后进先出（LIFO）。

数量相同 ≠ 有效")()("

2 个 '(' 和 2 个 ')'，但第一个 ')' 出现时前面没有任何开括号。只计数会误判，必须借助顺序。

最近的先闭合"[ ( ] )"

读到 ']' 时，最近未闭合的是 '(' 而不是 '['。闭括号只能匹配栈顶：能配上就 pop，配不上立即 return False。

匹配规则 / The two rules

  1. 遇到开括号（c 是 parentheses_map 的 key）→ stack.append(c)，压栈等待闭合。
  2. 遇到闭括号 → 若 stack 非空且 parentheses_map[stack[-1]] == c，stack.pop() 配成一对；否则 return False。
  3. 遍历结束后 return not stack：栈空说明所有开括号都已被闭合。

parentheses_map：一张表管三件事

映射开 → 闭{'('→')', '['→']', '{'→'}'}

三种括号各自的配对关系，写成一个哈希表 parentheses_map。

区分开与闭c in parentheses_map

字符在 map 的 key 里就是开括号，走 push 分支；否则是闭括号，走匹配分支。

查询栈顶在等谁parentheses_map[stack[-1]]

闭括号 c 到来时，查栈顶开括号期望的闭括号，相等才能 pop。

边界情况 / Edge cases

多余的开括号"(([]"

循环走完也没有 return False，但 stack = ['(', '('] 非空：return not stack 得到 False。无效只靠闭合时刻检查不出来，必须做收尾检查。

闭括号先来")()"

第一个 ')' 到来时栈为空，stack and ... 直接短路，返回 False；不会真的去取 stack[-1]。

类型不匹配"([]{)}"

')' 要闭合栈顶的 '{'，但 parentheses_map['{'] 是 '}'，立即返回 False。

空字符串""

循环一次也不执行，空栈取 not 得 True：零个括号天然有效。

复杂度 / Complexity

Time · O(n)

只遍历字符串一次；每个字符只做一次压栈或出栈，都是 O(1)。

Space · O(n)

栈最多存下全部 n 个开括号；parentheses_map 固定 3 对，占 O(1)。
