删除链表倒数第 k 个节点

例子：1 → 2 → 4 → 7 → 3；D 是放在 head 前面的 dummy 节点。

0 / 0 间距：0 条边

圆圈间实线：节点保存的 .next 方框细箭头：变量指向 变量细箭头会移向新目标；改 .next 时强调被修改的实线 下方虚线方框：trailer 所在节点的 .next 括号：当前两个指针相隔的边数

拖动 leader、trailer 或下方的 .next 到目标；也可先点方框，再点节点／None。键盘可用 Tab 和 Enter。自由练习不会推进演示。

关键区别：移动 leader／trailer 只改变变量的箭头；执行 trailer.next = trailer.next.next 才改变节点之间的实线。返回 dummy.next，才能处理删除原 head 的情况。

怎么想到双指针？

题目

删除单链表中倒数第 k 个节点，返回删除后的头节点。上方可选 k，再逐步看变量和链表怎样变化。

思路与原因

单链表不能往回走，所以要让 trailer 提前停在待删节点的前一个节点。先让 leader 从 dummy 向前走 k 条边，再让两个指针同步走；两者始终相隔 k 条边。

当 leader 到达尾节点时，trailer 到目标的前一个节点。比如 k = 2：leader 在 3，trailer 在 4，下一节点 7 正是倒数第 2 个。dummy 站在原头节点前面，因此删除头节点时也有一个“前一个节点”。

也可以按位置验证：若链表有 n 个真实节点，尾节点在第 n 位；trailer 落后 k 位，停在第 n - k 位，所以下一个就是倒数第 k 个节点。

解题步骤

  1. 令 dummy.next = head，leader 与 trailer 都从 dummy 出发。
  2. 只移动 leader 共 k 次；若途中到达 None，说明 k 超过链表长度。
  3. 只要 leader.next 存在，就把两个指针各向前移动一次。这里改的是变量的指向，节点里的 .next 没变。
  4. 执行 trailer.next = trailer.next.next，把目标从可达链表中跳过；返回 dummy.next 作为新头节点。

两个指针各最多走一遍链表：时间 O(n)，额外空间 O(1)。

跳过节点后，它去哪了？

以删除 7 为例，4 的 .next 改为指向 3。7 自己保存的 7.next → 3 没有被这行代码修改，但从新头节点已无法走到 7。如果程序没有保留别的引用，运行环境便可以回收它；返回的链表是 1 → 2 → 4 → 3。
