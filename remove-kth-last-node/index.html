删除链表倒数第 k 个节点

例子：1 → 2 → 4 → 7 → 3；D 是放在 head 前面的 dummy 节点。

0 / 0 间距：0 条边

圆圈间实线：节点保存的 .next 方框细箭头：变量指向 下方虚线方框：trailer 所在节点的 .next 括号：当前两个指针相隔的边数

拖动 leader、trailer 或下方的 .next 到目标；也可先点方框，再点节点／None。键盘可用 Tab 和 Enter。自由练习不会推进演示。

关键区别：移动 leader／trailer 只改变变量的箭头；执行 trailer.next = trailer.next.next 才改变节点之间的实线。返回 dummy.next，才能处理删除原 head 的情况。
