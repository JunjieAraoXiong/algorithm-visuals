Final Python / 最终代码

def linked_list_loop(head: ListNode) -> bool:    slow = fast = head     # Check both 'fast' and 'fast.next' before taking two hops    # so we never access '.next' on None.    while fast and fast.next:        slow = slow.next        fast = fast.next.next         if fast == slow:            return True     return False

Identity assumption / 身份比较前提： the source keeps fast == slow, which acts as identity when ListNode uses Python’s default equality. If __eq__ is overridden, use fast is slow to state object identity explicitly. / 源码保留 fast == slow；只有在 ListNode 使用默认相等规则时，它才等同于身份比较。若类重写了 __eq__，应使用 fast is slow 明确比较对象身份。

Baseline: remember every node / 基础解法：记住每个节点

A hash set asks whether the current node object is already stored. It takes linear time, but the shelf can grow to n nodes. / 哈希集合检查当前节点对象是否已经存过；时间为线性，但最多需要保存 n 个节点。

def linked_list_loop_naive(head: ListNode) -> bool:
    visited = set()
    curr = head
    while curr:
        if curr in visited:
            return True
        visited.add(curr)
        curr = curr.next
    return False

Time O(n), extra space O(n). Floyd keeps the time and removes the growing set. / 时间 O(n)，额外空间 O(n)；Floyd 方法去掉了不断增长的集合。

Race intuition and distance countdown / 跑道直觉与距离倒计时

Equal speeds preserve the gap. When fast moves two edges for every one edge taken by slow, it gains one node per iteration. / 速度相同会保持距离；当 fast 每轮走两步、slow 走一步时，fast 每轮追近一个节点。

1× and 1× / 同速

Both move one edge; the gap stays 0. / 都走一步，距离保持 0。

1× and 2× / 快慢速

slowfast0→slow1fast2

fast gains one node each iteration. / fast 每轮多走一个节点。

Now measure forward from fast to slow inside a cycle of length k. The final states are 2 → 1 → 0. / 现在按环方向量出从 fast 到 slow 的距离；最后三步是 2 → 1 → 0。

d → (d - 1) mod k. There are only k possible distances, so after both enter the cycle they meet within at most k iterations. / 环内只有 k 种距离；两者都入环后，最多再经过 k 轮就会相遇。

Why the guard is safe / 为什么循环条件安全

while fast and fast.next: short-circuits from left to right. The body reads fast.next.next only when both required references exist. / and 从左到右短路求值；只有两段引用都存在时，循环体才会读取 fast.next.next。

fast.next is never evaluated. / 不会读取 fast.next。

fast→last→Nonestop / 停止

The loop body does not run. / 不会进入循环体。

Solving steps / 解题步骤

  1. Start together / 同时起跑： slow = fast = head. Do not compare yet: they are equal only because both were initialized to head. / 此时先不比较；它们相同只是因为都刚被设为 head。
  2. Check two-hop room / 确认能走两步： require fast and fast.next. / 必须确认 fast 与 fast.next 都存在。
  3. Move / 移动： slow takes one stored edge; fast takes two. / slow 沿实线走一步，fast 沿实线走两步。
  4. Compare identity / 比较身份： compare only after movement. fast == slow means the same node object, not merely equal values. / 移动后才比较；相等必须表示同一个节点对象。
  5. Exit / 退出： meeting returns True; reaching None returns False. / 相遇返回 True；到达 None 返回 False。

Scope / 范围： this function only detects whether a cycle exists. Finding the cycle’s entry node is a separate second phase and is not part of this question. / 本题只判断是否有环；寻找入环节点属于另一阶段，不要混在这段代码里。
