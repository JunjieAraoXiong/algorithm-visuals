Linked List Intersection · 链表相交

0 / 0 第 0 轮

完整 Python 代码

class ListNode:    def __init__(self, val, next_node=None):        self.val = val        self.next = next_node  def get_intersection_node(head_A, head_B):    ptr_A, ptr_B = head_A, head_B     while ptr_A is not ptr_B:        ptr_A = ptr_A.next if ptr_A else head_B        ptr_B = ptr_B.next if ptr_B else head_A     return ptr_A

为什么换头后会相遇？

题目：给两条单向链表，找它们的第一个共同节点；若没有，返回 None。ptr_A 从 head_A 出发，ptr_B 从 head_B 出发；每轮各沿 .next 前进一步。

  1. 先认节点身份。两边的 4_A 和 4_B 值一样，却是不同对象。只有两个指针指向同一个圆圈，才算相交。
  2. 让路程相等。设 A 独有 a 个节点，B 独有 b 个，共同尾部有 c 个。从各自头部开始，到共同节点前，ptr_A 更新 a+c+1+b 次，ptr_B 更新 b+c+1+a 次。中间的 +1 是从 None 换到对方头部；两边次数相等。
  3. 到 None 后换头。只把指针变量改指向另一条链表的头，完全不修改任何节点的 .next。如果没有共同节点，两者走完 A 和 B 后会同时指向 None。

每一轮先更新 ptr_A，再更新 ptr_B；回到 while 顶部才比较。时间 O(len(A) + len(B))，额外空间 O(1)。
