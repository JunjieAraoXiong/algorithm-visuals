Palindromic Linked List

判断单链表从前往后、从后往前读是否相同。用 fast/slow 找中点，把从 mid 开始的后半段原地反转，再让两个指针逐个比较。

圆圈间的深色实线： 节点保存的 .next方框与细灰箭头： 变量引用节点虚线方框： 可修改的 .next 字段

点一个 节点.next，再点目标圆圈或 None，可自行改线；也可拖动字段到目标。自由练习不会推进演示，按上/下一步可回到对应代码状态。焦点在图上时可用 ← / → 切换。

同一个节点 ≠ 相同的值。 圆圈在所有步骤中保持位置与身份；反转只改 .next 实线。奇数例子里左右两条路径在中间的同一个节点 3 相遇。代码会修改原链表的连接，而且不会恢复它。

为什么这样做

  1. slow 一次走一步，fast 一次走两步；循环停止时 slow 指向 mid。偶数长度时它是后半段第一个节点。
  2. 从 mid 反转：先存 nextNode，再把 currNode.next 改为 prevNode；仅这一行改变节点里的连接。奇数长度包含中间节点。
  3. ptr1 从原 head 开始，ptr2 从反转后的 second_head 开始。只要 ptr2 未到 None 就逐个比较。即使某次不等，截图中的代码也继续比较，然后返回 False。

空链表时比较循环不执行，结果为 True。单节点也为 True。时间 O(n)，额外空间 O(1)。

完整 Python 代码

以下保留截图中的找中点、反转、比较逻辑；ListNode 定义补全了独立运行所需的节点类型。

class ListNode:
    def __init__(self, val: int, next=None):
        self.val = val
        self.next = next


def palindromic_linked_list(head: ListNode) -> bool:
    # Find the middle and reverse the list starting there.
    mid = find_middle(head)
    second_head = reverse_list(mid)

    # Compare the first half with the reversed second half.
    ptr1, ptr2 = head, second_head
    res = True
    while ptr2:
        if ptr1.val != ptr2.val:
            res = False
        ptr1, ptr2 = ptr1.next, ptr2.next
    return res


def reverse_list(head: ListNode) -> ListNode:
    prevNode, currNode = None, head
    while currNode:
        nextNode = currNode.next
        currNode.next = prevNode
        prevNode = currNode
        currNode = nextNode
    return prevNode


def find_middle(head: ListNode) -> ListNode:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow
