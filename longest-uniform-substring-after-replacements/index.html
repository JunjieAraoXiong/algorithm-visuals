Longest Uniform Substring After Replacements · 替换后的最长统一子串

Replace at most k = 2 characters so one substring contains only a single repeated character. Find the longest possible length.最多替换 k = 2 个字符，让某段子串全部变成同一个字符；求最长长度。

Final Python / 最终代码

def longest_uniform_substring_after_replacements(s: str, k: int) -> int:    freqs = {}    highest_freq = max_len = 0    left = right = 0    while right < len(s):        freqs[s[right]] = freqs.get(s[right], 0) + 1        highest_freq = max(highest_freq, freqs[s[right]])        num_chars_to_replace = (right - left + 1) - highest_freq        if num_chars_to_replace > k:            freqs[s[left]] -= 1            left += 1        max_len = right - left + 1        right += 1    return max_len

highest_freq is the largest frequency seen while growing a window. It may be a historical upper bound; that is enough to decide whether the current length can improve the answer. / highest_freq 是扩展过程中见过的最高频率，可能是历史上界；它足以判断当前长度能否刷新答案。

The one equation that drives the window / 驱动窗口的一条公式

Keep the most common character and replace every other character. The least replacements needed are therefore:

window length窗口长度−highest_freq保留最高频字符=replacements需要替换的字符数

replacements ≤ k

Valid budget: expand right and try a longer window. / 预算足够：继续扩展右端，尝试更长窗口。

replacements > k

Over budget: remove s[left], then move both boundaries forward. / 超出预算：移除左端字符，再让窗口整体右移。

Why highest_freq does not decrease / 为什么最高频率不需要减小

It is a historical target for beating the best length, not a promise that every later same-size window is currently valid. / 它是用来挑战更长答案的历史门槛，并不保证之后每个同长度窗口此刻都有效。

earlier valid / 先前有效
aaab

length 4 − highest 3 = 1. A valid length 4 has already been proved.

later same length / 后续同长度
aabc

Actual highest is 2, while stored highest_freq may remain 3. This cannot inflate the answer beyond 4; a longer answer is recorded only when the window grows. / 真实最高频为 2，但保存值可保持 3；它不会把答案虚增到 4 以上，只有窗口再次变长才会刷新答案。

Solving steps / 解题步骤

  1. Add s[right] to freqs.
  2. Update the historical highest_freq.
  3. Compute window length - highest_freq.
  4. If that exceeds k, remove one left character and advance left.
  5. Record the maintained window length, then advance right.

Complexity / 复杂度

Time / 时间 · O(n)

Each boundary moves only forward across the string. / 两个边界都只向前移动。

Extra space / 额外空间 · O(m)

m is the number of distinct characters stored in freqs. / m 是频率表中的不同字符数。
