Next Lexicographical Sequence · 下一字典序

Chapter 01 · Two Pointers / 双指针

Rearrange the same letters to produce the immediate next string in lexicographical order. If no larger arrangement exists, return the smallest arrangement.使用相同字符组成字典序中紧接着的下一个字符串；如果已经是最大排列，就返回最小排列。

Final Python / 最终代码

def next_lexicographical_sequence(s: str) -> str:    letters = list(s)    pivot = len(letters) - 2    while pivot >= 0 and letters[pivot] >= letters[pivot + 1]:        pivot -= 1    if pivot == -1:        return ''.join(reversed(letters))    rightmost_successor = len(letters) - 1    while letters[rightmost_successor] <= letters[pivot]:        rightmost_successor -= 1    letters[pivot], letters[rightmost_successor] = (        letters[rightmost_successor], letters[pivot]    )    letters[pivot + 1:] = reversed(letters[pivot + 1:])    return ''.join(letters)

non-increasing means every next character is smaller than or equal to the previous one; repeated characters are allowed. / “非递增”允许相邻字符相等。

What “next” means / “下一个”是什么意思

The answer is the first permutation larger than the input, so it must make the smallest possible increase.

All permutations of abc
  1. abc
  2. acb ← next after abc
  3. bac
  4. bca
  5. cab
  6. cba
Change as far right as possible
abcedda

Changing a later position creates a smaller lexicographical increase than changing an earlier one. / 越靠右的位置发生变化，整体增幅越小。

Three transformations / 三个关键变换

1 · Find pivot

Scan right to left until one character is smaller than the next.

c < e
2 · Smallest increase

Swap the pivot with the rightmost character larger than it.

c ↔ d
3 · Smallest suffix

Reverse the still non-increasing suffix.

edca → acde

Why reversing is enough / 为什么反转就够了

Before the swap, the suffix is non-increasing, which is its largest ordering. After swapping with the rightmost successor it remains non-increasing. Reversing it therefore produces its smallest ordering in O(n), with no sort.

  1. The pivot makes the overall string larger.
  2. Choosing the rightmost successor makes that increase as small as possible.
  3. Reversing the suffix minimizes everything after the pivot.

No pivot: wrap around / 找不到 pivot：回到最小排列

dcba→ reverse →abcd

dcba is already the largest permutation, so the next sequence wraps to abcd.

aaaa → aaaa

Equal adjacent letters are part of a non-increasing suffix; reversing identical characters changes nothing.

Complexity / 复杂度

Time · O(n)

At most two right-to-left scans and one suffix reversal.

Extra space · O(n) in Python

Strings are immutable, so letters = list(s) stores a mutable copy.
