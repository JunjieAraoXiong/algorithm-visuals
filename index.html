Algorithm Visuals

可逐步操作的算法图解。

  • Reverse Linked List · 迭代 — 拖动变量和节点的 .next，观察链表如何反转。
  • Reverse Linked List · 递归 — 跟着调用栈下潜与返回，观察每层如何反转指针。
  • Remove the Kth Last Node · 双指针 — 看 leader 与 trailer 如何保持间距，并从倒数第 k 个节点前方绕过它。
  • Linked List Intersection · 双指针 — 看两个指针换头后在同一节点相遇，并区分节点值与对象身份。
  • LRU Cache · 哈希表与双向链表 — 逐步观察查找、移动到最近使用端，以及容量满时淘汰最久未用的节点。
  • Flatten a Multi-Level Linked List · 展平多层链表 — 跟随 curr 与 tail，把子链表接到末尾并清除 child 引用。
