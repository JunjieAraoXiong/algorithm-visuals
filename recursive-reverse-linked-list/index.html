Recursive Reverse Linked List · 递归反转链表

    f(k) 表示 linked_list_reversal_recursive(head=节点 k)。基本情况：空链表或只有一个节点时，直接返回原来的 head；本例在 f(4) 遇到单节点。

    完整 Python 代码

    class ListNode:    def __init__(self, val: int, next=None):        self.val = val        self.next = next def linked_list_reversal_recursive(head: ListNode) -> ListNode:    if not head or not head.next:        return head     new_head = linked_list_reversal_recursive(head.next)    head.next.next = head    head.next = None    return new_head

    问题 给定链表 1 → 2 → 3 → 4 → None，反转节点间的 .next，返回新头 4。

    核心想法 递归先把 head.next 后面的链表反转；返回时，当前 head 才接到末尾。

    变量角色 head 是当前这一层待处理的节点；new_head 是后半段递归返回的原尾节点，也是最终新头。灰色细箭头只表示变量引用，不会修改节点之间的 .next。

    1. 走到空链表或最后一个节点，直接返回它，作为 new_head。
    2. 回退一层，用 head.next.next = head 把下一个节点的箭头反向指回 head。
    3. 用 head.next = None 断开原来的箭头，否则两个节点暂时成环；逐层返回同一个 new_head。

    为什么可行 每层只处理一个 head，较短的后半段已反转。反向接回时旧的 head → head.next 仍在，暂时出现双向环；清掉 head.next 后，当前节点成为新尾。每层返回的仍是同一个原尾节点。时间 O(n)；递归调用栈空间 O(n)。
