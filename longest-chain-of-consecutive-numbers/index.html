Final Python / 最终代码

def longest_chain_of_consecutive_numbers(nums: list[int]) -> int:    if not nums:        return 0    num_set = set(nums)    longest_chain = 0    for num in num_set:        if num - 1 not in num_set:            current_num = num            current_chain = 1            while current_num + 1 in num_set:                current_num += 1                current_chain += 1            longest_chain = max(longest_chain, current_chain)    return longest_chain

A set membership check is average O(1). We expand a chain only from its smallest value. / 集合查询平均为 O(1)；只有链中最小的数字才会向后扩展。

From repeated searching to one pass / 从重复搜索到一次扩展

The decisive improvement has two parts: put every value in a hash set, then refuse to expand from the middle of a chain.

Sort first / 先排序

O(n log n)

Consecutive values become neighbors, but sorting costs more than a linear scan.

Set, every value starts / 每个值都起步

O(n²)

Membership is fast, but the same chain is walked again from 5, 6, 7, and 8.

Set, only real starts / 只从真正链头起步

O(n)

Expand from num only when num - 1 is absent.

Why the predecessor test works / 为什么检查前一个数字

num = 6

5→6→7→8

5 exists, so 6 is inside an existing chain. Starting here would repeat work.

num = 5

5→6→7→8

4 is absent, so 5 is the unique start of this chain.

  1. Every finite consecutive chain has exactly one smallest value.
  2. Only that smallest value has no predecessor in the set.
  3. Therefore every chain is expanded exactly once.

Edge cases / 边界情况

[] → 0

The early return handles an empty input. / 空数组直接返回 0。

[1, 2, 2, 3] → 3

The set removes duplicates; the chain remains 1, 2, 3. / 集合去重，不影响连续链长度。

[-2, -1, 0] → 3

The predecessor rule works the same for negative values.

[10] → 1

A single value is a chain of length one.

Complexity / 复杂度

Time · O(n) average

The outer loop checks every unique value once, and all chain-growth steps together visit at most every unique value once.

Extra space · O(n)

num_set stores the unique input values.
