可拖动方框到圆圈或 null，也可先点方框、再点目标（键盘用 Tab 与 Enter）。下方虚线方框用于改动节点的 .next。

题目与思路

把 1 → 2 → 3 → null 反转为 3 → 2 → 1 → null。prev_node 是已反转部分的头，curr_node 是尚未处理部分的头。

  1. 先保存 next_node = curr_node.next，否则改线后会丢失剩余链表的入口。
  2. 执行 curr_node.next = prev_node，这一步才修改节点保存的实线。
  3. 让 prev_node = curr_node、curr_node = next_node，继续处理下一个节点。

每轮结束时，prev_node 指向已反转部分，curr_node 指向剩余部分；当 curr_node = null，返回 prev_node。时间 O(n)，额外空间 O(1)。
