Cutting Wood · 砍木头

Given heights = [2, 6, 3, 8] and k = 7, set the woodcutter to the highest integer height H (0 ≤ H ≤ max(heights)) so that cutting the top off every tree taller than H yields at least k meters of wood.给定树高数组 heights = [2, 6, 3, 8] 和整数 k = 7。电锯设在整数高度 H，所有高过 H 的树被切去顶部，求能切到至少 k 米木材的最高 H。

完整 Python 代码

def cutting_wood(heights: List[int], k: int) -> int:    left, right = 0, max(heights)    while left < right:        # Bias the midpoint to the right during the upper-bound binary        # search.        mid = (left + right) // 2 + 1        if cuts_enough_wood(mid, k, heights):            left = mid        else:            right = mid - 1    return right # Determine if the current value of 'H' cuts at least 'k' meters of# wood.def cuts_enough_wood(H: int, k: int, heights: List[int]) -> bool:    wood_collected = 0    for height in heights:        if height > H:            wood_collected += (height - H)    return wood_collected >= k

每调用一次 cuts_enough_wood 都遍历整个树高数组；cutting_wood 对它做 O(log m) 次调用。

直觉：H 越大，木材越少 / Monotonic wood

每棵树贡献 max(0, height − H) 米，所以把 H 从 0 逐渐调高，总木材只减不增。二分搜索的对象是 H 的取值轴，不是树高数组——数组本身无需有序。

H = 0 · 切得最多2 + 6 + 3 + 8 = 19 m

锯子贴地，所有树都被整棵切下。任何 k ≤ 19 都一定够。

H = 8 · 切得最少0 m

锯子和最高的树齐平，一棵树都切不到。H 再高也没有意义。

判定函数 cuts_enough_wood

把每棵树高过 H 的部分加起来，和 k 比较：wood_collected = Σ max(0, height − H)，返回 wood_collected >= k。

H = 3 · 可行(6−3) + (8−3) = 8 ≥ 7

返回 True；3 是候选答案。比 3 更高的设置还要再验证。

H = 4 · 不可行(6−4) + (8−4) = 6 < 7

返回 False；H = 4 及其以上全部排除。

所有 True 排在所有 False 之前：布尔结果构成一个有序序列，目标“最高的可行 H”就是这个序列里最后一个 True（upper bound / 上界）。

上界二分：两种情况 / Two cases

Case 1 · cuts_enough_wood(mid) 为 True

mid 可行，说明答案 ≥ mid：区间缩到 [mid, right]，执行 left = mid，保留 mid 继续向右找。

Case 2 · cuts_enough_wood(mid) 为 False

mid 太高，说明答案 < mid：区间缩到 [left, mid − 1]，执行 right = mid − 1，弃掉 mid。

mid = (left + right) // 2 + 1 向右偏置：当 right = left + 1 时 mid 落在 right 上，两种分支都会让区间变小，不会死循环。循环结束时 left == right，它就是最后一个 True。

边界情况 / Edge cases

k 一定能达到

题目保证 H = 0 总能切够，所以答案必然存在，left 从 0 开始不会落空。

k = 0

任何 H 都“够”，循环一路把 left 推到 max(heights)，返回最高可设的高度。

H 的上限

H > max(heights) 时一根木材也切不到，又比 max(heights) 本身更“不够”，所以右边界就是 max(heights)。

只有一棵树

区间仍是 [0, heights[0]]，同样的二分照常进行。

复杂度 / Complexity

Time · O(n log m)

在 [0, m]（m = max(heights)）上做二分，共 O(log m) 轮；每轮调用 cuts_enough_wood 遍历数组一次 O(n)。合计 O(log m) · O(n) = O(n log m)。

Extra space · O(1)

只保存 left、right、mid 和累加器 wood_collected。
