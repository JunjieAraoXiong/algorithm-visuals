Unique ID Generator 唯一 ID 生成器

两台机器各自生成编号：哪些字段避免重复，什么时候必须停止发号？

发号状态

需求

先规定：编号不能重复，能放进 64 位，并大致按时间排序。

先区分唯一与有序

多个服务都需要创建记录。这里要求数值编号全局唯一、占用 64 位，并大致按时间排序，不要求相邻编号加一。

Worker A → id_a
Worker B → id_b
要求：id_a ≠ id_b

代价与边界

时间有序不等于跨机器请求的严格先后顺序；这是模拟发号器，不连接真实时钟或服务。

步骤 1 / 15

唯一性来自约束

同一时刻，机器身份不能重复；同一机器，同一毫秒内序列不能重复。

机房与机器编号需要统一分配。进程重启不能直接清空状态并在旧时间点重发；必须持久化高水位、等待安全时间或采用有保护的身份分配策略。本例把这部分作为部署前提。

与短链接的关系

一个 64 位编号不会自动变成七位短码。

完整 Base62 编码保留唯一性，但可能需要 11 位。当前短链接例子的七位上限依赖 id < 62^7；不能把本页的编号截断后直接替换进去。
