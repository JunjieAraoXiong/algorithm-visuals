Final Python / 最终代码

from collections import defaultdictdef geometric_sequence_triplets(nums: list[int], r: int) -> int:    left_map = defaultdict(int)    right_map = defaultdict(int)    count = 0    for x in nums:        right_map[x] += 1    for x in nums:        right_map[x] -= 1        if x % r == 0:            count += left_map[x // r] * right_map[x * r]        left_map[x] += 1    return count

right_map[x] is decremented before counting, so the current index can never be chosen as its own right-hand element. / 计数前先从 right_map 移除当前 x，因此当前下标不会被误当成自己的右侧元素。

Choose the middle value / 固定中间值

Once x is fixed as the middle value, the other two values are forced. The maps answer how many valid choices exist on the correct side of the current index.

Important details / 重要细节

defaultdict(int)

A missing key reads as frequency 0. / 不存在的键默认频率为 0。

x % r != 0

No integer left value exists, so this x contributes nothing.

r = 1

All three values are equal; the same frequency logic counts different index choices.

r ≠ 0

This implementation assumes a nonzero common ratio because it divides by r.

Complexity / 复杂度

Time · O(n) average

Two array passes perform average constant-time hash-map operations.

Extra space · O(n)

The two frequency maps can contain up to O(n) distinct keys.
