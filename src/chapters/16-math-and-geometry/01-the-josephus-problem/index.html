The Josephus Problem · 约瑟夫问题

n people stand in a circle, numbered from 0. Starting at person 0, count k people clockwise and remove the k-th; the count restarts from the next person. Return the position of the last person standing.n 个人围成一圈，从 0 开始编号。从 0 号开始顺时针数 k 个人，淘汰第 k 个，再从下一个人重新数。返回最后剩下那个人的编号。

Final Python / 最终代码

def josephus(n: int, k: int) -> int:    # 基础情况：只剩一个人，他的编号是 0    if n == 1:        return 0    # 先求 n - 1 人时的幸存者编号，    # 再平移 k 位映射回 n 人时的编号    return (josephus(n - 1, k) + k) % n

字母表示同一个人；数字是他在当前这一层调用里的编号。

The circle / 直接模拟

以 n = 5, k = 2 为例：每次数到第 2 个人就把他淘汰。直接模拟需要真的维护一个圈，删除 n − 1 次。

淘汰顺序
递归视角

淘汰一个人后，剩下的 n − 1 人正好是一个规模更小的同类问题——只是“0 号”变成了被淘汰者的下一位。只要知道小问题的答案，再把编号平移回来即可。

Why (survivor + k) % n / 为什么是加 k 取模

在 n 人的圈里，第一个被淘汰的是编号 (k − 1) % n，新一轮从编号 k % n 开始数，于是它在 n − 1 人的问题里成为新的 0 号。

新编号 p → 旧编号 (p + k) % n

新 0 号是旧 k % n 号，新 1 号是旧 (k + 1) % n 号……每个新编号都比旧编号少了 k，绕过圈尾时取模回到开头。

被淘汰的人不会被映射到

新编号只有 0 … n − 2，加 k 后取模正好跳过旧编号 (k − 1) % n，也就是被淘汰的那个人。

Iterative version / 迭代写法

自底向上
def josephus_optimized(n: int, k: int) -> int:
    res = 0
    for i in range(2, n + 1):
        res = (res + k) % i
    return res
同一条递推

递归返回时做的事就是从 1 人一路映射到 n 人。迭代版直接按 i = 2 … n 的顺序算，省掉 O(n) 的调用栈。上面的例子：res 从 0（1 人）开始，依次变为 0 → 2 → 0 → 2。

Edge cases / 边界情况

n = 1

不用淘汰任何人，答案是 0。

k = 1

每次淘汰当前第一个人，最后留下的是 n − 1 号；递推 (res + 1) % i 也给出同样结果。

k > n

数的时候会绕圈多次；取模已经处理了绕圈，公式不变。

k = 2

有闭式解：把 n 写成 2^m + l（0 ≤ l < 2^m），幸存者编号是 2l。例子中 5 = 4 + 1，答案 2。

Complexity / 复杂度

Time · O(n)

从 n 递归到 1，每层 O(1)。

Space · O(n) / O(1)

递归版占用 n 层调用栈；迭代版只用一个变量。
