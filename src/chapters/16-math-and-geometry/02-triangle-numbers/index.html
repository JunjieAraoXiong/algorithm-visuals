Triangle Numbers · 三角形数字

The top row of a triangle is 1. Each number below is the sum of the three numbers above it (top-left, top, top-right; missing numbers count as 0). Given a row number n ≥ 3, return the position of the first even number in that row (positions start at 1).三角形顶端是 1。下面每个数等于它左上、正上、右上三个数之和（不存在的按 0 算）。给定行号 n（n ≥ 3），返回这一行第一个偶数的位置（位置从 1 开始）。

Final Python / 最终代码

#（观察用）暴力生成下一行def next_row(row: List[int]) -> List[int]:    padded = [0, 0] + row + [0, 0]    return [padded[i] + padded[i + 1] + padded[i + 2]            for i in range(len(row) + 2)] #  规律：从第 3 行起，前 4 个位置的奇偶每 4 行重复def triangle_numbers(n: int) -> int:    # 奇数行：位置 2 是第一个偶数    if n % 2 != 0:        return 2    # 4 的倍数行：位置 3 是第一个偶数    elif n % 4 == 0:        return 3    # 其余偶数行：位置 4 是第一个偶数    return 4

next_row 只用来找规律；真正的答案 triangle_numbers 是 O(1)。

The full triangle / 完整三角形

每一行左右对称，第 n 行有 2n − 1 个数，中间位置是 n。所以只看左半边就能找到第一个偶数；演示里只画位置 1 到 n。

Why only four positions / 为什么只看前 4 个位置

  1. 位置 1 永远是 1（上面只有一个 1，另外两个按 0 算），所以位置 1 不会是偶数。
  2. 位置 p 只由上一行的位置 p − 2、p − 1、p 决定。所以“前 4 个位置的奇偶”只取决于上一行“前 4 个位置的奇偶”。
  3. 从第 3 行起，上一行至少有 5 个数，所以计算前 4 个位置不会碰到右侧边界，规则每行都一样。第 7 行前 4 个位置的奇偶与第 3 行完全相同，之后每一行都由上一行唯一决定，于是整个模式以 4 行为周期重复：奇数行 → 2，4 的倍数行 → 3，其余偶数行 → 4。
  4. 每个周期里第一个偶数都落在位置 2、3 或 4，所以不必看更远的位置。

Edge cases / 边界情况

n = 1, 2

这两行全是 1，没有偶数；题目约定 n ≥ 3。若要处理它们，可以先判断并返回 -1。

很大的 n

数字本身会指数增长，暴力生成既慢又占内存；规律只用到 n % 4。

Complexity / 复杂度

Time · O(1)

只做两次取模判断。（暴力生成到第 n 行是 O(n²)。）

Space · O(1)

不需要保存任何一行。
