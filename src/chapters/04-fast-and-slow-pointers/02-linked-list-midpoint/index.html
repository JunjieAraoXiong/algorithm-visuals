Linked List Midpoint · 链表中点

Return the middle node of a singly linked list. When the length is even, return the second middle. Watch slow move one edge while fast moves two.返回单链表的中间节点；长度为偶数时返回第二个中点。观察 slow 每轮走一步，fast 每轮走两步。

Noneslowfast

Final Python / 最终代码

def linked_list_midpoint(head: ListNode) -> ListNode:    slow = fast = head     # When fast reaches the end, slow is at the midpoint.    while fast and fast.next:        slow = slow.next        fast = fast.next.next     return slow

Even-length rule / 偶数规则： this guard lets slow move once more when fast is on the first middle, so the returned node is the second middle. / 当 fast 位于第一个中点时，条件仍允许再走一轮，因此返回第二个中点。

Baseline: traverse twice / 基础方法：扫描两遍

The first pass counts n; the second pass moves n // 2 edges. It is still O(n), but the pointer revisits the prefix. / 第一遍得到长度 n，第二遍前进 n // 2 步。时间仍为 O(n)，但链表前半段被重复访问。

Why odd and even lists stop differently / 奇偶长度为何停在不同位置

Every completed loop adds 1 to slow's index and 2 to fast's index. The same guard handles both endings. / 每完成一轮，slow 的下标增加 1，fast 增加 2；同一个条件同时处理两种结尾。

fast.next is None → slow is the only middle. / slow 位于唯一中点。

even length / 偶数长度

fast is None → slow is the second middle. / slow 位于第二个中点。

If the interviewer wants the first middle / 如果要求第一个中点

For an even list, stop one loop earlier by requiring room for two complete future edges. / 偶数长度时提前一轮停止：只有未来两条边都存在才继续。

def first_middle(head: ListNode) -> ListNode:
    slow = fast = head
    while fast.next and fast.next.next:
        slow = slow.next
        fast = fast.next.next
    return slow

Solving steps / 解题步骤

  1. Start together / 同时起点： slow = fast = head.
  2. Check two-hop room / 检查两步空间： continue only when fast and fast.next exist.
  3. Move at 1× and 2× / 一倍速与两倍速： slow takes one edge; fast takes two.
  4. Return the reference / 返回引用： when the loop stops, slow points to index ⌊n / 2⌋.

Complexity / 复杂度

Time / 时间 · O(n)

fast traverses at most the whole list once. / fast 最多经过整条链表一次。

Extra space / 额外空间 · O(1)

Only two node references are stored. / 只保存两个节点引用。
