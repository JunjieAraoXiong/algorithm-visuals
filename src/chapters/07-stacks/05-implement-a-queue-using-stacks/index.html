Implement a Queue Using Stacks · 用栈实现队列

Implement a queue using only the stack data structure: enqueue(x) adds x to the back, dequeue() removes and returns the front, and peek() returns the front. No other data structures are allowed, and dequeue / peek are only called on a non-empty queue. For example, [enqueue(1), enqueue(2), dequeue(), enqueue(3), peek()] outputs [1, 2].只用栈实现队列：enqueue(x) 把 x 加到队尾；dequeue() 移除并返回队首；peek() 返回队首。不允许使用其他数据结构；题目保证 dequeue / peek 只在队列非空时调用。例子：[enqueue(1), enqueue(2), dequeue(), enqueue(3), peek()] 的输出是 [1, 2]。

完整 Python 代码

class Queue:    def __init__(self):        self.enqueue_stack = []        self.dequeue_stack = []    def enqueue(self, x: int) -> None:        self.enqueue_stack.append(x)    def transfer_enqueue_to_dequeue(self) -> None:        # If the dequeue stack is empty, push all elements from the enqueue stack        # onto the dequeue stack. This ensures the top of the dequeue stack        # contains the least recently added value.        if not self.dequeue_stack:            while self.enqueue_stack:                self.dequeue_stack.append(self.enqueue_stack.pop())    def dequeue(self) -> int:        self.transfer_enqueue_to_dequeue()        # Pop and return the value at the top of the dequeue stack.        return self.dequeue_stack.pop() if self.dequeue_stack else None    def peek(self) -> int:        self.transfer_enqueue_to_dequeue()        return self.dequeue_stack[-1] if self.dequeue_stack else None

栈顶在上方。左栈 enqueue_stack 只接收 enqueue；右栈 dequeue_stack 只服务 dequeue / peek，其栈顶永远是队首。

直觉：队列和栈差在哪 / FIFO vs FILO

队列是先进先出（FIFO），栈是后进先出（FILO）。差别只在从哪一端驱逐元素：队列从队首出，栈从栈顶出。同一组数 1、2、3 依次入队，出来仍是 1、2、3；依次入栈，出来却是 3、2、1。

题目只允许用栈。只用一个栈的话，先到的 1 会沉在栈底，而每次 dequeue 要取的正是它。朴素做法：把压在它上面的值一个个倒进临时栈 temp，取走 1 后再全部 push 回来——结果正确，但每次访问队首都要搬动全部元素，单次 O(n)。

关键观察：倒进 temp 之后，temp 的栈顶（2）正是下一个该出队的值——所以「push 回来」这一步可以省掉，让 temp 留下来专门服务之后的 dequeue。这个留下的 temp 就是 dequeue_stack；原来的栈只负责 enqueue，成为 enqueue_stack。

两个栈的分工 / Why it works

enqueue_stack 的栈顶永远是最新入队的值；当 dequeue_stack 为空时，把 enqueue_stack 一次性全部倒入 dequeue_stack——顺序整体反转，最早的值正好落在栈顶。从此每次 dequeue / peek 只认 dequeue_stack 的栈顶。

不变量 / Invariant

dequeue_stack 的栈顶 = 剩余元素中最早入队的值（队首）。元素在左栈期间不会被访问，进右栈后只从栈顶离开。

只在空时搬运 / Transfer on empty

右栈非空时，它的栈顶就是正确队首；此时搬运反而让新元素压到旧元素上面，破坏顺序。所以 if not self.dequeue_stack 是唯一的搬运时机。

一次倒完 / All at once

while 循环把左栈一次搬空。只倒一半会让较旧的元素压在较新的上面，顺序同样错乱——搬运必须完整。

均摊 O(1) / Amortized

每个元素一生只从左栈搬到右栈一次；n 次 dequeue 的总搬运量不超过 n 次，平均到每次 dequeue 是 O(1)。

边界情况 / Edge cases

dequeue / peek 只在非空时调用

题目保证。此时若右栈空，左栈必有元素，transfer 之后栈顶一定存在——代码里 else None 分支永远不会走到。

连续 enqueue 后的第一次 dequeue

一次搬空整个左栈，这一次 dequeue 是 O(n)；但每个元素只被搬这一次，均摊下来仍是 O(1)。

enqueue 永远不触发搬运

3 进左栈时右栈还压着 2，「不搬」是正确性的关键，不是偷懒：搬了反而让 3 压到 2 上面。

peek 与 dequeue 只差一步

peek 读 dequeue_stack[-1] 而不弹出，所以下一步 dequeue 拿到的仍是同一个值。

复杂度 / Complexity

Time · enqueue O(1)，dequeue / peek 均摊 O(1)

enqueue 只压一次栈。dequeue / peek 的单次最坏情况是 O(n)（搬空左栈），但每个元素一生只搬一次，n 次操作的总搬运量 ≤ n，均摊 O(1)。

Extra space · O(n)

两个栈合起来恰好存下队列的全部元素，任何时刻元素总数就是队列长度 n。
