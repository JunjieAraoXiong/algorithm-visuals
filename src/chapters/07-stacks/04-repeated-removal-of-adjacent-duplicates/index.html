Repeated Removal of Adjacent Duplicates · 反复移除相邻重复项

Continually remove a pair of adjacent duplicates from a string until no adjacent duplicates remain, and return the final string. For example, s = "aacabba" returns "c", and s = "aaa" returns "a".给定字符串 s，反复移除一对相邻的重复字符，直到字符串中不再含有相邻重复，返回最终剩下的字符串。例如 s = "aacabba" 返回 "c"，s = "aaa" 返回 "a"。

完整 Python 代码

def repeated_removal_of_adjacent_duplicates(s: str) -> str:    stack = []    for c in s:        # If the current character is the same as the top character on the stack,        # a pair of adjacent duplicates has been formed. So, pop the top character        # from the stack.        if stack and c == stack[-1]:            stack.pop()        # Otherwise, push the current character onto the stack.        else:            stack.append(c)    # Return the remaining characters as a string.    return ''.join(stack)

stack[-1] 是栈顶字符，也就是「正在构建的新字符串」的最后一个字符；每来一个新字符 c，唯一可能形成相邻重复的位置就是栈顶，所以只需比较一次。

直觉：边构建、边消去 / Build and cancel

把结果字符串从左到右逐个字符地构建。新字符 c 到来时，它只会和「新字符串的最后一个字符」相邻——因此只要把已经构建的部分放在一个栈里，栈顶 stack[-1] 就是那个唯一的邻居：相等说明相邻重复对形成，弹出栈顶（当前 c 也随之丢弃）；不等就压入栈。

栈 = 正在构建的新字符串

栈底到栈顶依次就是新字符串从左到右的字符，stack[-1] 是它的最后一个字符。返回时 ''.join(stack) 按从底到顶的顺序拼回去即可。

相同 → 成对消去

c == stack[-1] 时，两者构成一对相邻重复：stack.pop() 删旧字符，当前 c 不入栈——两个一起消失，相当于从字符串里删掉这一对。

不同 → 压栈

c != stack[-1] 时压入栈。由于栈里本来就没有相邻重复，压入一个不同的字符之后仍然没有，不变量保持成立。

为什么恰好是栈

整个过程只需要两种操作：在同一端添加字符、在同一端删除字符。栈的 append 和 pop 正好就是这两个 O(1) 操作。

为什么一次遍历就够 / Why one pass works

不变量：处理完每个字符后，栈中任意相邻两项都不相同，所以栈恰好等于「当前前缀反复移除后的结果」。新字符 c 唯一可能与之构成重复的邻居就是栈顶；其它相邻关系在之前的步骤里已被消除，而弹出只动栈顶、不打乱其余顺序。于是每个字符只做一次比较、至多一次 push 或 pop，永不回扫，总代价 O(n)。

最容易漏掉的是「移除后才相邻」的重复对。演示中第 12–14 步（s = "aacabba" 的两个 'b' 和最后一个 'a'）就是关键时刻：'bb' 弹出后，新的栈顶自动暴露为左边那个 'a'，它和最后的 'a' 只隔着已消去的 'bb'——无需回头检查，栈顶天然就位。这正是 "abba" 这类嵌套重复也能正确处理的原因。

a acabba先形成的重复对：开头的 "aa"
↓cab ba移除 "aa" 后：中间的 "bb"
↓ca a移除 "bb" 后：两个 "a" 现在相邻
↓c= "c"移除最后一对，剩下答案

顺序由左到右的扫描天然决定：每对重复都是「后一个字符到达时」才被发现的，所以一遍扫描不会漏掉任何一对。

边界情况 / Edge cases

"aaa" → "a"

奇数个连续相同字符最后落单一个：前两个 'a' 在第二个字符到来时消去，第三个 'a' 入栈后没有相同邻居，留在栈里。

"aaaa" → ""

偶数个连续字符两两消尽，栈变空；继续在空栈上扫描也安全——stack and ... 短路，不会真的去取 stack[-1]。

"abba" → ""

嵌套重复：移除 "bb" 暴露 "aa"，再消尽。最终返回空字符串 ""（对空列表 join 的结果）。

"" 与 "abc"

空字符串循环一次也不执行，直接返回 ""；完全没有重复的字符串一路压栈，原样返回 "abc"。

复杂度 / Complexity

Time · O(n)

只遍历字符串一次；每个字符最多入栈一次、出栈一次，append 和 pop 都是 O(1)；结尾 join 至多拼接 n 个字符，也是 O(n)。

Space · O(n)

栈最坏保存全部 n 个字符（如 s = "abc"）。按书中约定，返回的输出字符串所占空间不计入空间复杂度。
