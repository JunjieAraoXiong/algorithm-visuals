Shortest Path · 最短路径

Given an integer n representing nodes labeled from 0 to n - 1 in an undirected graph, and an array of non-negative weighted edges, return an array where each index i contains the shortest path length from a specified start node to node i. If a node is unreachable, set its distance to -1. Each edge is a triplet: [start, end, weight]. Example: n = 6, edges = [[0,1,5],[0,2,3],[1,2,1],[1,3,4],[2,3,4],[2,4,5]], start = 0 → [0, 4, 3, 7, 8, -1].给定 n 个节点（编号 0 到 n-1）的带权无向图，返回 start 到每个节点的最短路径长度；不可达的节点距离记为 -1，每条边是 [起点, 终点, 权重] 三元组。书例：n=6、start=0，答案是 [0, 4, 3, 7, 8, -1]——节点 5 与图不连通，所以是 -1。

curr_node
curr_dist
min_heap 大小

完整 Python 代码

def shortest_path(n: int, edges: List[int], start: int) -> List[int]:    graph = defaultdict(list)    distances = [float('inf')] * n    distances[start] = 0    # Represent the graph as an adjacency list.    for u, v, w in edges:        graph[u].append((v, w))        graph[v].append((u, w))    min_heap = [(0, start)]  # (distance, node)    # Use Dijkstra's algorithm to find the shortest path between the start node    # and all other nodes.    while min_heap:        curr_dist, curr_node = heapq.heappop(min_heap)        # If the current distance to this node is greater than the recorded        # distance, we've already found the shortest distance to this node.        if curr_dist > distances[curr_node]:            continue        # Update the distances of the neighboring nodes.        for neighbor, weight in graph[curr_node]:            neighbor_dist = curr_dist + weight            # Only update the distance if we find a shorter path to this            # neighbor.            if neighbor_dist < distances[neighbor]:                distances[neighbor] = neighbor_dist                heapq.heappush(min_heap, (neighbor_dist, neighbor))    # Convert all infinity values to -1, representing unreachable nodes.    return [-1 if dist == float('inf') else dist for dist in distances]

直觉：选 Dijkstra / Choosing the algorithm

单源最短路的四个候选：BFS 只适合无权（等权）图；Bellman-Ford 容忍负权边；Floyd-Warshall 求全点对；Dijkstra 管“非负权 + 单源”——正是本题。它的过程像涟漪：从 start 出发，每轮取当前距离最小的未确定节点，把它“定死”，再用它的出边尝试松动邻居的距离（松弛）。

为什么是“取最小者定死”而不是别的？这就是贪心选择：当前已知距离最小的节点，不可能再通过别的未确定节点变得更近——任何绕路都必须先经过某个距离已经不小于它的节点，而非负权意味着之后只会更长。于是它的 distances 值就是最终答案。

过时条目：不需要 visited 集合 / Stale heap entries

堆允许同一个节点暂存多个条目：节点 1 先以 (5, 1) 入堆，后来经 0→2→1 把它改进到 4，又压入 (4, 1)。两个条目都在堆里，先弹出 (4, 1) 把节点 1 定死；之后弹出的 (5, 1) 一比对 curr_dist > distances[curr_node] 便知是旧账，直接 continue。所以代码不需要单独的 visited 集合——首次弹出即确定，再弹到的都是过时条目。

书中特别演示过：去掉这个检查，节点 1 会被以更大的 curr_dist 重复访问一次（书中原图 0→1 边权取 6，于是条目是 (6, 1)；本页示例该边权为 5，条目是 (5, 1)，机制完全相同）。

为什么贪心成立，以及非负权前提 / Why it works

局部最优 ⇒ 全局最优 / Greedy is safe

弹出 curr_node 时，它的 curr_dist 是所有未确定节点的已知距离里最小的。任何另一条到 curr_node 的路径，第一步必须离开已确定集合、踏入某个 distances ≥ curr_dist 的节点；从那里走到 curr_node 还要再加非负的边权，所以不可能更短。它的距离就此确定。

负权会让论证失效 / Non-negative only

若有负权边，“绕路只会更长”不再成立——先走远路再被负边拉回反而可能更短，此时“距离最小者先确定”是错的。负权图请改用 Bellman-Ford；本题边权非负，Dijkstra 安全。

边界情况 / Edge cases

不可达节点 → -1

节点 5 没有任何邻接边，distances[5] 始终是 ∞，收尾的列表推导统一把 ∞ 转成 -1。无需在循环里特判。

起点即终点

distances[start] = 0 在建堆前就写好，(0, start) 第一个被弹出、第一个确定，天然正确。

重边与自环

邻接表照单全收：重边只是多一个候选，松弛时自动取最小；自环的候选值 curr_dist + w ≥ curr_dist（非负权），永远不可能触发更新。

距离并列

堆按 (distance, node) 二元组比较：距离相等再比节点编号，与 Python tuple 顺序一致，结果与手写 heapq 完全同步。

复杂度 / Complexity

Time · O((n + e) log n)

建邻接表 O(e)。主循环里每个节点只确定一次，每条边最多触发一次松弛入堆；每次 heappush / heappop 是 O(log n)，合计 O((n + e) log n)。

Space · O(n + e)

邻接表存 2e 条 (邻居, 权) 记录，O(n + e)；distances O(n)；堆里每个节点至多一个有效条目加少量待清理的过时条目，O(n)。
