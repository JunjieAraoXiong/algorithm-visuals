Connect the Dots · 连接所有点

Medium · 中等 — Kruskal / 克鲁斯卡尔算法 · Union-Find / 并查集

Given a set of points on a plane, determine the minimum cost to connect all these points. The cost of connecting two points is the Manhattan distance |x1 - x2| + |y1 - y2|. Example: points = [[1,1],[2,6],[3,2],[4,3],[7,1]] → output 15. There will be at least 2 points.平面上有一组点，求把所有点连通的最小代价；连接两点的代价是 Manhattan 距离 |x1-x2|+|y1-y2|。例子：points = [[1,1],[2,6],[3,2],[4,3],[7,1]]，输出 15。点数至少为 2。

def connect_the_dots(points: List[List[int]]) -> int:    n = len(points)    # Create and populate an array containing all possible edges.    edges = []    for i in range(n):        for j in range(i + 1, n):            # Manhattan distance.            cost = (abs(points[i][0] - points[j][0]) + abs(points[i][1] - points[j][1]))            edges.append((cost, i, j))    # Sort the edges by their cost in ascending order.    edges.sort()    uf = UnionFind(n)    total_cost = 0    edges_added = 0    # Use Kruskal's algorithm to create the MST and identify its minimum cost.    for cost, p1, p2 in edges:        # If the points are not already connected (i.e., their representatives        # are not the same), connect them, and add the cost to the total cost.        if uf.union(p1, p2):            total_cost += cost            edges_added += 1        # If n - 1 edges have been added to the MST, the MST is complete.        if edges_added == n - 1:            return total_costclass UnionFind:    def __init__(self, size):        self.parent = [i for i in range(size)]        self.size = [1] * size    def union(self, x, y) -> bool:        rep_x, rep_y = self.find(x), self.find(y)        if rep_x != rep_y:            if self.size[rep_x] > self.size[rep_y]:                self.parent[rep_y] = rep_x                self.size[rep_x] += self.size[rep_y]            else:                self.parent[rep_x] = rep_y                self.size[rep_y] += self.size[rep_x]            # Return True if both groups were merged.            return True        # Return False if the points belong to the same group.        return False    def find(self, x) -> int:        if x == self.parent[x]:            return x        self.parent[x] = self.find(self.parent[x])        return self.parent[x]

直觉：连线题就是最小生成树 / From dots to MST

建模 / Modeling

每个点是图的一个节点；任意两点之间都可以连边，边权 = Manhattan 距离 |x1-x2|+|y1-y2|。n 个点构成完全图，共 n(n-1)/2 条候选边。目标变成：选总权值最小的一组边把所有节点连通——最小生成树（MST）。

为什么是树 / Why a tree

连通 n 个点至少需要 n-1 条边；若有环，环上任取一条边删掉仍连通，总代价不增。所以最优解一定可以取成无环的 n-1 条边——一棵树。

Kruskal 的贪心 / Greedy order

把所有边按代价从小到大逐个尝试：边的代价越小越该选，唯一不能选的理由是「两个端点已经连通，再连成环」。用并查集判连通，不成环就采用，直到选满 n-1 条。

并查集：判环与合并 / Union-Find

union(x, y) 返回 True 表示 x、y 原本不连通，这次合并成功——该边采用；返回 False 表示两点已在同一组，加入必成环——跳过。合并时按 size 挂接（小树挂到大树的根下），让树尽量矮，find 更快；find 顺带做路径压缩，把沿途节点直接指向根。书例中 (0,3) 和 (1,3) 都因两端同组（代表都是 3）被跳过。

为什么按 size 挂接 / Union by size

把大树挂到小树下面会让树变高，find 要走的层数变多。每次让较小的树挂到较大的根下，任意节点的深度不超过 O(log n)。

路径压缩 / Path compression

find 递归返回根之后，顺手把沿途每个节点的 parent 直接改写为根。本例链条最长只有两层，改写前后数组看起来一样；点更多时它会明显加速后续的 find。

为什么贪心正确 / Why it works

切割性质：任取图的一个切割（把节点分成两组），所有跨越该切割的边中权值最小者，必属于某一棵最小生成树。Kruskal 取当前最小边 (u, v) 时，u、v 必不连通——取「u 所在组 vs 其余节点」这个切割，(u, v) 正是跨越它的最小边（代价更小的边早已被处理过，两端早已连通），所以把它选入是安全的。被跳过的边两端同组，加入只会成环、替换不掉任何更优选择。

边界情况 / Edge cases

只有 2 个点

唯一的一条边就是答案：edges_added == 1 == n-1，直接返回它的 Manhattan 距离。

多点共线 / 距离相等

共线不影响距离公式；代价相等时 edges.sort() 继续比较元组 (cost, i, j) 的后两项，先比 i 再比 j。本页仿真按同样的顺序排序，与原 Python 逐事件一致。

提前返回

选满 n-1 条边后立即 return，剩余边不再处理——书例中 (3,4)、(0,1)、(0,4)、(1,4) 四条边永远不会被检查。

n 较大时

n² 条边全部生成再排序是瓶颈；Prim 算法配合堆可以把时间降到 O(n² log n) 以下（稠密图可 O(n²)），代价是失去「逐条边贪心」的直观。

复杂度 / Complexity

Time · O(n² log n)

完全图有 n(n-1)/2 = O(n²) 条边，排序耗 O(n² log n)；之后每条边至多一次 union（按 size 合并 + 路径压缩，摊还近乎常数），合计 O(n²)。总计 O(n² log n)。

Space · O(n²)

edges 数组保存全部 O(n²) 条边；并查集的 parent / size 只需 O(n)。
