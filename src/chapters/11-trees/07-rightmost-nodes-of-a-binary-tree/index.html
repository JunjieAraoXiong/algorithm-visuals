Rightmost Nodes of a Binary Tree · 二叉树每层最右节点

Return the rightmost node value at every depth, viewed from the right side.取每一层最右的节点。图片里的 11 比右侧分支更深，所以仍然可见。

完整 Python 代码

from typing import List, Optional class TreeNode:    def __init__(self, val=0, left=None, right=None):        self.val = val        self.left = left        self.right = right from collections import deque def rightmost_nodes_of_a_binary_tree(root: Optional[TreeNode]) -> List[int]:    if not root:        return []    res = []    queue = deque([root])    while queue:        level_size = len(queue)        for i in range(level_size):            node = queue.popleft()            if node.left:                queue.append(node.left)            if node.right:                queue.append(node.right)            if i == level_size - 1:                res.append(node.val)    return res

最右分支会在 6 提前结束

图片中根的右侧分支是 1 → 3 → 6，但左子树还有更深的 11。右视图要求「每个深度的最右节点」，因此答案是 [1, 3, 6, 11]。

队列为什么能找到最右节点

先加入左孩子，再加入右孩子。若本层从左到右出队，孩子也会从左到右排进下一层；这个顺序从只有根的一层开始一直成立。

level_size 是本层的边界

本层循环只执行开始时的 len(queue) 次。弹出 2 后把 4、5 入队，它们也不能在当前层被处理。i == level_size - 1 才是本层的最后一个。

完整过程与边界

入队根；冻结一层的大小；依次出队并入队孩子；最后一个值写入 res；队列非空时重复。节点只读，树中的 left、right 没有改变。

空树与单侧树

空树返回 []。单侧树的每层只有一个节点，因此所有节点都会被记录；不需要特殊遍历分支。

时间与空间

O(n) 时间，每个节点各入队、出队一次。辅助队列 O(w)，w 是最大实际层节点数，最坏 O(n)。输出另占 O(h)，h 是层数。
