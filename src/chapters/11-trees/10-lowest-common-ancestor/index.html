Lowest Common Ancestor · 最近公共祖先

Find the lowest node whose subtree contains both distinct target nodes, including the node itself.p、q 都存在于树中。图片中的 8 与 7 在节点 3 会合。

完整 Python 代码

from typing import List, Optional class TreeNode:    def __init__(self, val=0, left=None, right=None):        self.val = val        self.left = left        self.right = right lca = None def lowest_common_ancestor(root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:    global lca    lca = None  # Reset the saved answer for each call.    dfs(root, p, q)    return lca def dfs(node: Optional[TreeNode], p: TreeNode, q: TreeNode) -> bool:    global lca    if not node:        return False    node_is_p_or_q = node == p or node == q    left_contains_p_or_q = dfs(node.left, p, q)    right_contains_p_or_q = dfs(node.right, p, q)    if node_is_p_or_q + left_contains_p_or_q + right_contains_p_or_q == 2:        lca = node    return node_is_p_or_q or left_contains_p_or_q or right_contains_p_or_q

两个目标第一次在两个区域会合

把一个节点分成「自己、左子树、右子树」三个互不重叠的区域。p、q 是不同且存在于树中的节点，因此恰好两个区域命中就说明它们在这里会合。图片里的 p=8、q=7 在节点 3 的两侧，答案是 3。

三个成立的情况

self=False、L=True、R=True：两侧各一个。self=True、L=True、R=False：当前节点和左侧。self=True、L=False、R=True：当前节点和右侧。节点本身也可以是祖先。

同在一侧时不要提早设置答案

切换 p=8、q=9：节点 3 只有左区域为 True，不能成为最近的祖先。更低的 6 已经在两侧找到目标，返回的单个 True 不表示「只有一个目标」。

布尔返回值和节点答案各做一件事

dfs 返回当前子树是否包含 p 或 q；lca 保存节点引用。后序遍历先解决更低的子树。LCA 之上的节点只看到一个命中区域，不会再次满足和为 2，所以最深的答案不会被覆盖。

完整过程与重复调用

每层计算 self，再递归左右，检查三个布尔值之和，必要时保存 lca，最后返回 OR。保留图片中的全局变量策略，但外层每次重置 lca，连续查询不会串用旧答案。

约束与复杂度

假设 p、q 不同，且都存在于这棵树；比较节点引用，不靠值寻找目标。O(n) 时间，O(h) 调用栈，最坏 O(n) 空间。None 子树返回 False。
