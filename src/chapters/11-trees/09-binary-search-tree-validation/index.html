Binary Search Tree Validation · 二叉搜索树验证

Validate a strict binary search tree: every value must satisfy all ancestor bounds.保持原图的两处错误：左子树里的 6 超过根 5，右子树出现重复 7。

完整 Python 代码

from typing import List, Optional class TreeNode:    def __init__(self, val=0, left=None, right=None):        self.val = val        self.left = left        self.right = right def binary_search_tree_validation(root: Optional[TreeNode]) -> bool:    return is_within_bounds(root, float('-inf'), float('inf')) def is_within_bounds(node: Optional[TreeNode], lower_bound: float, upper_bound: float) -> bool:    if not node:        return True    if not lower_bound < node.val < upper_bound:        return False    if not is_within_bounds(node.left, lower_bound, node.val):        return False    return is_within_bounds(node.right, node.val, upper_bound)

父子大小正确，仍然可能不是 BST

图片中的 6 大于父节点 2，局部看起来正确。但 6 位于根 5 的左子树，所有这些后代都必须小于 5。另外右侧还包含两个 7，严格 BST 不允许相等。

边界携带祖先的限制

根从 (-∞, ∞) 开始。走左侧保留下界、把上界换成当前 val；走右侧保留上界、把下界换成当前 val。到 6 时边界是 (2,5)，祖先 5 的限制没有丢失。

调用栈不是另一棵树

栈中的 node 是引用，lower_bound、upper_bound 是这一层调用的局部值。返回到父调用时，父的边界仍然保留；树中的 left、right 从不改变。

严格不等式与短路顺序

先检查当前值，再验证左子树；左侧失败便直接返回 False，右侧跳过。原图首先发现 6 越界，所以实际执行不会再访问右侧的重复 7。切换「只保留重复 7」可以单独看到相等边界失败。

为什么能覆盖整棵子树

如果当前值在边界内，并且左右子树在收紧后的边界内也都正确，那么它们每个后代都符合当前节点及所有祖先的要求。None 返回 True，让叶子自然结束。

时间与空间

最多访问 n 个节点，O(n) 时间；发现错误可提前返回。递归栈 O(h)，最坏 O(n)。用 ±∞ 表示无边界，允许正常的负数节点值。
