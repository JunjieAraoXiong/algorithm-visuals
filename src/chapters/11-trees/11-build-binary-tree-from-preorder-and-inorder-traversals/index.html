完整 Python 代码

class TreeNode:    def __init__(self, val=0, left=None, right=None):        self.val = val        self.left = left        self.right = right class Solution:    def buildTree(self, preorder, inorder):        preorder_index = 0        inorder_indexes_map = {val: i for i, val in enumerate(inorder)}         def build_subtree(left, right):            nonlocal preorder_index             if left > right:                return None             val = preorder[preorder_index]            inorder_index = inorder_indexes_map[val]            node = TreeNode(val)            preorder_index += 1             node.left = build_subtree(left, inorder_index - 1)            node.right = build_subtree(inorder_index + 1, right)             return node         return build_subtree(0, len(inorder) - 1)

What changed and why

The earlier version already reconstructed the correct tree. This revision keeps that algorithm and makes its shared state, recursive boundaries, and return values easier to follow.

One shared cursor per reconstruction

preorder_index and inorder_indexes_map now belong to buildTree instead of the module. Each new call gets fresh state without manually resetting globals. The nested helper reads the enclosing arrays and map, so only left and right need to be passed recursively.

preorder_index += 1 rebinds an integer. nonlocal preorder_index tells Python to update the enclosing variable shared by all helper calls; without it, Python treats the name as local and the read fails. The map is only read, so it needs no nonlocal declaration. Each helper call still has its own bounds and node.

Less repetition, clearer state changes

The example now has 64 frames instead of 90: initialization takes two frames, and each of the seven empty child calls takes two instead of four. Every nonempty call keeps its execution order. Labels such as 9.left = 2 identify the receiving node; explicit True/False results explain each branch. The inorder partitions and call overview connect a steadily advancing cursor with the changing subtree ranges.

Fewer animation frames improve readability. They do not change the algorithm's time complexity.

Why the reconstruction works

At the start of every nonempty build_subtree(left, right) call, preorder[preorder_index] is the root of exactly the subtree described by that inclusive inorder range. The inputs must be valid traversals of the same tree, with equal lengths and unique values.

Preorder chooses the root; inorder splits the children

Preorder visits root → left → right, so the next unused value chooses the root. Its unique inorder position splits [left, right] into [left, inorder_index - 1] and [inorder_index + 1, right]. With root 5 at index 2, these are [0,1] for 2 and 9, and [3,5] for 4, 3, and 7. Passing bounds avoids copying or deleting array elements.

The cursor advances once for the root. Building the entire left subtree first consumes exactly its preorder values, so the cursor then points to the right subtree's root. Here, after creating 5, 9, and 2, preorder_index = 3 correctly selects 3.

Return a complete subtree before attaching it

An empty range returns None without consuming a preorder value. Otherwise, both smaller ranges are reconstructed by the same rule. After their calls return, assigning node.left and node.right attaches their root references. Returning node therefore returns the complete current subtree.

Creating a node and attaching it to its parent are separate events: return 9 returns the subtree rooted at 9, and only the next receiving step writes 5.left = 9. Two empty input arrays immediately produce an empty range and return None.

Time and space complexity

Let n be the number of nodes and h the tree height. These bounds describe the Python reconstruction, excluding the visualization's saved animation frames.

Time: O(n)

Building the position map takes O(n). Each node is created once, with an average O(1) dictionary lookup and constant work outside its recursive calls. The n + 1 empty child calls also take constant time each. Total time is O(n), assuming average constant-time dictionary operations. The earlier version already used a position map; changing to nonlocal and a dictionary comprehension preserves this bound.

Auxiliary space: O(n + h) = O(n)

The map stores n entries, and the deepest active recursion chain uses O(h) stack frames. A balanced tree has h = O(log n); a completely skewed tree has h = O(n). The map keeps total auxiliary space at O(n) in both cases. The returned tree separately requires O(n) output space; including it still gives O(n) total extra space.
