Build Binary Tree From Preorder and Inorder Traversals · 从前序与中序遍历构建二叉树

Reconstruct a binary tree from its preorder and inorder traversals with unique values.跟随图片中的两组数组：前序决定创建顺序，中序决定子树范围。

完整 Python 代码

from typing import List, Optional class TreeNode:    def __init__(self, val=0, left=None, right=None):        self.val = val        self.left = left        self.right = right preorder_index = 0inorder_indexes_map = {} def build_binary_tree(preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:    global preorder_index, inorder_indexes_map    preorder_index = 0  # Reset both globals for each reconstruction.    inorder_indexes_map = {}    for i, val in enumerate(inorder):        inorder_indexes_map[val] = i    return build_subtree(0, len(inorder) - 1, preorder, inorder) def build_subtree(left: int, right: int, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:    global preorder_index, inorder_indexes_map    if left > right:        return None    val = preorder[preorder_index]    inorder_index = inorder_indexes_map[val]    node = TreeNode(val)    preorder_index += 1    node.left = build_subtree(left, inorder_index - 1, preorder, inorder)    node.right = build_subtree(inorder_index + 1, right, preorder, inorder)    return node

一条遍历顺序不够，两条顺序各补一个信息

前序 [5,9,2,3,4,7] 先告诉我们根是 5，却不能单独决定左子树有多大。中序 [2,9,5,4,3,7] 把 5 左侧的 2、9 分到左子树，把 4、3、7 分到右子树。再在每个范围里重复这个逻辑。

前序游标：下一个创建谁

新建 5 后游标指向 9。必须先完成整个左子树，才轮到右侧的 3。每个非空调用消耗一个值，空范围不消耗，因此不需要另找前序子数组。

中序闭区间：哪些值属于这里

根所在位置 inorder_index 把 [left,right] 拆为 [left,inorder_index-1] 和 [inorder_index+1,right]。范围为空就返回 None；边界不需要从数组中删除。

节点创建和指针接上是两个时刻

TreeNode(val) 只创建当前节点，孩子都是 None。node.left 的递归调用返回以后，才把左子树根引用写进 .left；.right 同理。图中等待返回的节点可以已创建而尚未连到父节点。

完整过程与重复调用

建立 inorder_indexes_map；重置 preorder_index；按中序范围递归；读取前序根，查中序分界，新建节点，前序索引加一；先左后右构建并接边，返回节点。外层重置两个全局变量，保持图片策略且支持重复调用。

前提与复杂度

两组遍历必须来自同一棵树，长度相同且值唯一；这些是输入前提。空数组返回 None。O(n) 时间，位置表 O(n)、栈 O(h)，不计输出树；输出本身另占 O(n)。
