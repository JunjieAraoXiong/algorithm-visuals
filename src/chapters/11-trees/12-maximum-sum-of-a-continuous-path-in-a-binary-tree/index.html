Maximum Sum of a Continuous Path in a Binary Tree · 二叉树最大路径和

Find the greatest sum of a nonempty simple path in a binary tree. The path may start and end anywhere.路径连续且不能分叉，也不必经过根。图片中的最佳路径 9 → 8 → 7 → 6，和为 30。

完整 Python 代码

from typing import List, Optional class TreeNode:    def __init__(self, val=0, left=None, right=None):        self.val = val        self.left = left        self.right = right max_sum = float('-inf') def max_path_sum(root: TreeNode) -> int:    global max_sum    max_sum = float('-inf')  # Reset for each nonempty input tree.    max_path_sum_helper(root)    return max_sum def max_path_sum_helper(node: Optional[TreeNode]) -> int:    global max_sum    if not node:        return 0    left_sum = max(max_path_sum_helper(node.left), 0)    right_sum = max(max_path_sum_helper(node.right), 0)    max_sum = max(max_sum, node.val + left_sum + right_sum)    return node.val + max(left_sum, right_sum)

每条合法路径都有一个最高点

一条不重复节点的路径向上走到最高点，再沿另一侧向下。在那个节点处，左右两臂可以合成一个完整候选，所以遍历每个最高点就不会漏掉任何答案。图片中最佳路径是 9 → 8 → 7 → 6，和为 30。

候选：允许左右两臂

在 8，left_sum=9，right_sum=13（7+6）。候选 8+9+13=30 可以更新全局 max_sum；这是在当前节点结束组合的一条合法路径。

返回：父节点还要接一条边

向上只能返回 8+max(9,13)=21。这个值表示以 8 为端点的最好单臂路径，保留一个端点才能继续接到父节点。

把 30 向上传，会出现三条分支

根 5 左侧可返回 2。如果错误地使用右侧完整候选 30，就会得到 5+2+30=37；在节点 8 同时接父节点、9、7，已不是一条连续路径。正确的根候选是 5+2+21=28，因此全局答案仍是 30。

错误：在 8 出现三个方向

两臂候选已经用掉 8 的两个方向，再接父节点会分叉。

正确：8 只返回一臂 21

单臂返回留出与父节点相连的方向；灰带表示 8+7+6。

负分支可以舍弃，节点本身不能凭空消失

父调用用 max(child_return,0) 去掉负贡献；当前节点仍必须计入。全负输入从 -∞ 更新，所以会选最大的负数，而不是不存在的空路径 0。

完整过程与状态重置

递归左右得到单臂和；把负臂截为 0；用当前值＋两臂更新 max_sum；返回当前值＋较大单臂。保留图片中的全局策略，并在每次外层调用重置 max_sum，连续计算不会继承旧答案。

复杂度与输入前提

题目保证树非空。None 只是递归孩子的边界，返回 0。每个节点处理一次，O(n) 时间、O(h) 栈空间，最坏 O(n)。示例中的完整候选 30 与根返回值 26 是不同量。
