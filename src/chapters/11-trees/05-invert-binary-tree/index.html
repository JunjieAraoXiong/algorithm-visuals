Invert Binary Tree · 翻转二叉树

Invert a binary tree by swapping every node’s left and right subtrees.把整棵树左右镜像。递归由 Python 保存调用栈；迭代用 stack 保存待处理节点。两者都交换子树引用，节点值不变。

完整 Python 代码

from typing import List, Optional class TreeNode:    def __init__(self, val=0, left=None, right=None):        self.val = val        self.left = left        self.right = right def invert_binary_tree_recursive(root: Optional[TreeNode]) -> Optional[TreeNode]:    if not root:        return None    root.left, root.right = root.right, root.left    invert_binary_tree_recursive(root.left)    invert_binary_tree_recursive(root.right)    return root def invert_binary_tree_iterative(root: Optional[TreeNode]) -> Optional[TreeNode]:    if not root:        return None    stack = [root]    while stack:        node = stack.pop()        node.left, node.right = node.right, node.left        if node.left:            stack.append(node.left)        if node.right:            stack.append(node.right)    return root

return None 后，究竟回到哪里？

每次递归调用都有自己的一份 root，以及「子调用结束后从哪里继续」的位置。调用子函数时，当前这一层暂停；子函数 return 时，只弹出最上面那一层，恢复直接调用它的那一层。None 是返回值；决定回到哪里的是调用栈保存的位置。

左调用返回 → 继续右调用

以叶子 4 为例：root = 4 那一层的 invert_binary_tree_recursive(root.left) 调用到 None，执行 return None。回到 root = 4 的那一层，左调用语句结束，接下来执行 invert_binary_tree_recursive(root.right)。不是直接回到整棵树的根。

右调用返回 → 当前层 return root

4 的右空孩子也返回 None 后，root = 4 的那一层才执行 return root，把节点 4 的引用返回给 root = 8 的那一层。8 从自己的左调用后继续；如果它还有右调用，就先完成它。

返回值和原地修改是两回事

这份代码没有写 root.left = invert_binary_tree_recursive(root.left)。子调用的返回值不用于赋值；左右引用早已在 root.left, root.right = root.right, root.left 中原地修改。返回时不再交换，不重新创建树。最外层 return root 把翻转后的整棵树入口交回调用者。

迭代栈保存的内容不同

递归栈保存每层的 root 和暂停位置；显式 stack 只保存待处理的节点引用。这份迭代代码不把 None 入栈，因此不会为每个空孩子执行 return None。栈清空后统一 return root。

镜像从一对引用开始

对称轴两边交换的是位置。先交换根的左右入口，原来 1 下方的 7、6 会一起换边；随后在每个子树内做同样的交换，才能得到完整镜像。

递归：把问题交给两个子树

每次调用保证「返回时，这个 root 下方已经翻转」。空树直接返回；非空树交换后，递归处理新的左、右子树。两个更小的问题完成后，当前子树也完成。

栈：保存尚未处理的入口

pop 一个节点，交换它的两条子指针，再将非空孩子入栈。先入左、再入右，所以右孩子先处理；遍历次序不同，但每个节点恰好交换一次。

哪些状态真的改变

node 或递归 root 改指向只改变变量。交换 left、right 才修改节点保存的边；val 从未被修改。两次完整翻转会恢复原树。

空树与叶子

None 返回 None。叶子的两条 None 引用互换后仍是叶子，不需要特判。

时间与空间

两种方法都是 O(n) 时间。递归占 O(h) 调用栈；显式 DFS 栈也至多 O(h)，最坏 O(n)。h 为树高，不包含原树本身。
