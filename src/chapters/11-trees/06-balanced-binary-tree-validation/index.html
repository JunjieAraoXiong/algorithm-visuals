Balanced Binary Tree Validation · 平衡二叉树验证

Check whether every node’s left and right subtree heights differ by at most one.每个节点都必须平衡。图片里的根 5 局部平衡，内部的 7 却不平衡。

完整 Python 代码

from typing import List, Optional class TreeNode:    def __init__(self, val=0, left=None, right=None):        self.val = val        self.left = left        self.right = right def balanced_binary_tree_validation(root: Optional[TreeNode]) -> bool:    return get_height_imbalance(root) != -1 def get_height_imbalance(node: Optional[TreeNode]) -> int:    if not node:        return 0    left_height = get_height_imbalance(node.left)    right_height = get_height_imbalance(node.right)    if left_height == -1 or right_height == -1:        return -1    if abs(left_height - right_height) > 1:        return -1    return 1 + max(left_height, right_height)

根看起来平衡，不代表整棵树平衡

示例中 5 的两侧高度都是 3，但 7 的左侧为空（0），右侧高度为 2。只检查根会漏掉内部的失衡；定义要求每个节点都满足高度差至多 1。

把高度和验证合成一次后序遍历

先问左右孩子的结果。两侧都有效且差值合格，当前节点返回 1 + max(left_height, right_height)。这让父调用既得到高度，也知道下面所有节点已通过检查。

-1 不是高度

失衡节点返回 -1，祖先看到它也返回 -1。否则，若 7 返回普通高度 3，根会看到 3 与 3，从而把坏子树掩盖。

递归的边界与代价

None 返回 0；叶子返回 1。图片中的实现先求两边，再检查 -1，因此左边已失衡时仍会遍历右边；动画保持这个执行顺序。

为什么一次就够

每个节点只读取两个孩子已经算好的结果，不重复计算整棵子树的高度。O(n) 时间，O(h) 递归栈；退化链最坏 O(n) 空间。

平衡案例与空树

移除 9 下方的 6 后，7 的高度差变为 1，整棵树通过。空树没有违反条件的节点，验证结果为 True。
