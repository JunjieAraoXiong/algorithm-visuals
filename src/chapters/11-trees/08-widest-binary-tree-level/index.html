Widest Binary Tree Level · 二叉树最大层宽

Find the maximum span between the leftmost and rightmost real nodes of a level, including gaps.宽度包括两端之间的空位。最深层有 4 个节点，但图片中的跨度是 7。

完整 Python 代码

from typing import List, Optional class TreeNode:    def __init__(self, val=0, left=None, right=None):        self.val = val        self.left = left        self.right = right from collections import deque def widest_binary_tree_level(root: Optional[TreeNode]) -> int:    if not root:        return 0    max_width = 0    queue = deque([(root, 0)])    while queue:        level_size = len(queue)        leftmost_index = queue[0][1]        rightmost_index = leftmost_index        for _ in range(level_size):            node, i = queue.popleft()            if node.left:                queue.append((node.left, 2 * i + 1))            if node.right:                queue.append((node.right, 2 * i + 2))            rightmost_index = i        max_width = max(max_width, rightmost_index - leftmost_index + 1)    return max_width

数节点会丢掉中间的空位

最深层的值是 8、9、11、14，只有 4 个真实节点。但图片中的位置编号是 7、8、10、13，跨度为 13 − 7 + 1 = 7。空位保留在位置里，不需要真的创建或入队。

编号是隐式的完整二叉树位置

根是 0。编号 i 的两个孩子占 2*i+1 和 2*i+2。即使左孩子缺失，右孩子也不会挤到左侧，这正是空位仍被保留的原因。

为什么只需要两端

BFS 保持从左到右的队列顺序。层开始时的 queue[0][1] 是左端；本层循环最后一次得到的 i 是右端。它们之间的所有位置都属于宽度。

层边界与边缘情况

每层先固定 level_size，再逐个出队、分配孩子编号。层结束后更新 max_width。值 val 与位置 i 无关；示例里的 14 恰好位于 i=13。

空树与链

空树宽度为 0。只有一条链时，无论编号多大，每层都只有同一个左右端，所以宽度为 1；两端之外的空位不计入。

时间与空间

按通常整数运算计 O(n) 时间、O(w) 队列空间，最坏 O(n)。Python 的编号不会溢出，但很深的树会产生大整数；实际整数运算代价会随位数增长。
