Kth Smallest Number in a Binary Search Tree · 二叉搜索树中第 K 小的数

def kth_smallest_number_in_BST_recursive(root: TreeNode, k: int) -> int:    sorted_list = inorder(root)    return sorted_list[k - 1]# Inorder traversal function to attain a sorted list of nodes from the BST.def inorder(node: TreeNode) -> List[int]:    if not node:        return []    return inorder(node.left) + [node.val] + inorder(node.right)# ----- 迭代版 iterative：显式栈 + 提前退出，只需前 k 个 -----def kth_smallest_number_in_BST_iterative(root: TreeNode, k: int) -> int:    stack = []    node = root    while stack or node:        # Move to the leftmost node and add nodes to the stack as we go so they        # can be processed in future iterations.        while node:            stack.append(node)            node = node.left        # Pop the top node from the stack to process it, and decrement 'k'.        node = stack.pop()        k -= 1        # If we have processed 'k' nodes, return the value of the 'k'th smallest        # node.        if k == 0:            return node.val        # Move to the right subtree.        node = node.right

直觉：中序遍历天然有序 / Inorder is sorted

朴素做法无视 BST 的性质：遍历所有节点值存进数组、排序，再取下标 k-1——O(n log n)。BST 的定义本身就是排序规则：左子树全部 < 根 < 右子树全部，所以「左 → 根 → 右」的中序遍历不费任何额外比较就输出升序数组，取 sorted_list[k-1] 即得答案。遍历本身是 O(n)，但本页 Python 的列表拼接还有复制成本，见下方复杂度。

但答案只依赖前 k 个元素，递归版却不得不访问完全部 n 个节点才返回。迭代版用显式栈复刻递归的调用栈：一路向左压栈模仿下探，弹栈顶 = 取出当前最小未访问节点，同时 k -= 1；一旦 k == 0 立即返回，剩下的节点根本不访问。

为什么中序遍历结果是升序 / Why it works

归纳地看：对任意子树，中序先完整输出左子树，再输出根，最后输出右子树。由 BST 性质，左子树的每个值都小于根、右子树的每个值都大于根，所以根恰好排在左、右两段之间；而左、右子树自身也是中序遍历，内部同样有序。层层归并，整棵树的中序输出就是全局升序。弹栈顶的迭代版同理：内层 while 走完左链后，栈顶才是当前最小未访问节点；下探过程中，栈顶的左边可能仍有更小的值，所以第 k 次弹出的节点就是第 k 小。

边界情况 / Edge cases

k = 1：最小值

一路向左压栈到头的那个节点（本例的 2）。迭代版第一轮 pop 即返回；递归版同样最先访问它。

k = n：最大值

中序的最后一个节点（本例的 9）。迭代版无法提前退出，两版都访问全部 n 个节点。

链树退化

单边链的树高 h = n。全左链先压入 n 个节点，栈空间 O(n)；全右链每次只压一个，栈空间 O(1)。迭代版仍只弹出前 k 个节点，但左链的初始下探可能走完整棵树。

k 保证合法

约束 1 ≤ k ≤ n，答案必存在，代码无需特判空树或 k 越界；n ≥ 1 保证 root 非空。

复杂度 / Complexity

递归版 · Time O(nh) 上界 · Space O(n)

h 为树的层数。访问节点本身是 O(n)，但 Python 的 + 会复制左右列表，每层都可能复制 O(n) 个值：平衡树 O(n log n)，链树 O(n²)，一般上界 O(nh)。峰值列表与递归栈合计 O(n)；用共享列表 append 的另一种实现才可达到 O(n) 时间。

迭代版 · Time O(k + h) · Space O(h)

返回前弹栈 k 次；压栈次数最多为 k+h，即已弹出的 k 个节点，加上栈里最多 h 个节点。因此时间 O(k+h)，栈空间 O(h)（最坏 O(n)），无需保存全部节点值。
