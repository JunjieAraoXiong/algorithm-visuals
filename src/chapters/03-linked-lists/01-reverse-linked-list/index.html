Linked List Reversal · 反转链表

步骤 1 / 14

完整 Python 代码

class ListNode:    def __init__(self, val: int, next=None):        self.val = val        self.next = next def reverse_linked_list(head: ListNode) -> ListNode:    prev_node = None    curr_node = head     while curr_node:        next_node = curr_node.next        curr_node.next = prev_node        prev_node = curr_node        curr_node = next_node     return prev_node

题目与思路

把 1 → 2 → 3 → None 反转为 3 → 2 → 1 → None。prev_node 是已反转部分的头，curr_node 是尚未处理部分的头。

  1. 先保存 next_node = curr_node.next，否则改线后会丢失剩余链表的入口。
  2. 执行 curr_node.next = prev_node，这一步才修改节点保存的实线。
  3. 让 prev_node = curr_node、curr_node = next_node，继续处理下一个节点。

每轮结束时，prev_node 指向已反转部分，curr_node 指向剩余部分；当 curr_node 是 None，返回 prev_node。时间 O(n)，额外空间 O(1)。
