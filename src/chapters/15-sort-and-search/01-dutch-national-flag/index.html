Dutch National Flag · 荷兰国旗问题

Given an array of 0s, 1s, and 2s, sort it in place in a single pass so all 0s come first, then 1s, then 2s.数组只含 0、1、2。只遍历一次、原地修改，让所有 0 在前、1 在中间、2 在最后。

left right i 0 1 未处理 2

Final Python / 最终代码

def dutch_national_flag(nums: List[int]) -> None:    i, left, right = 0, 0, len(nums) - 1    while i <= right:        # 0：和 left 处交换，0 区向右扩一格        if nums[i] == 0:            nums[i], nums[left] = nums[left], nums[i]            left += 1            i += 1        # 2：和 right 处交换，2 区向左扩一格        elif nums[i] == 2:            nums[i], nums[right] = nums[right], nums[i]            right -= 1        # 1：已经在中间区，直接跳过        else:            i += 1

Four regions / 四个区间

三个指针把数组切成四段。每一轮只检查 nums[i]，把它放进正确的一段，让“未处理”区缩小一格。

01未处理2
[0, left)[left, i)[i, right](right, n)

Why i moves differently / 为什么 i 的移动不对称

nums[i] == 0 → swap with left, i += 1

left ≤ i。如果 left < i，nums[left] 位于 1 区，换到 i 的一定是 1，已经检查过；如果 left == i，就是和自己交换。两种情况 i 都可以前进。

nums[i] == 2 → swap with right, i stays

nums[right] 来自未处理区，可能是 0、1 或 2。它被换到 i 后还需要在下一轮检查，所以只缩小 right。

Edge cases / 边界情况

[]

right = -1，循环一次都不执行。

[2, 2, 2]

每轮都和自己或右边的 2 交换，right 一路减到 -1，i 始终为 0。

[0, 0, 0]

i == left，每次都是自交换，两个指针一起前进。

循环条件 i <= right

用 <=：i == right 时那一格仍未检查。

Complexity / 复杂度

Time · O(n)

每一轮要么 i 加 1，要么 right 减 1，未处理区每轮缩小一格，最多 n 轮。

Space · O(1)

原地交换，只用三个下标。
