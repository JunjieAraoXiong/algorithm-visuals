Sum Between Range · 区间求和

Given an integer array, write a function which returns the sum of values between two indexes. Build the object from nums once, then answer each sum_range(i, j) in constant time.给定整数数组，编写函数返回两个下标 i 与 j 之间所有元素的和。先用 nums 做一次预处理，之后每次 sum_range(i, j) 查询都在 O(1) 内完成。

不变量 / Invariant

output

完整 Python 代码

class SumBetweenRange:    def __init__(self, nums: List[int]):        self.prefix_sum = [nums[0]]        for i in range(1, len(nums)):            self.prefix_sum.append(self.prefix_sum[-1] + nums[i])     def sum_range(self, i: int, j: int) -> int:        if i == 0:            return self.prefix_sum[j]        return self.prefix_sum[j] - self.prefix_sum[i - 1]

构造函数只在开始时运行一次；每个 sum_range 查询只读 prefix_sum 的 1–2 个元素，不再遍历 nums。

示例 / Example

Three queries on the same array; the gray cells are the range summed each time. 三次查询落在同一个数组上，灰色格子是每次被求和的区间。

sum_range(0, 3) / (2, 4) / (2, 2)
sum_range(0, 3) 30 -71 62 03 -24 55 sum = 2
sum_range(2, 4) 30 -71 62 03 -24 55 sum = 4
sum_range(2, 2) 30 -71 62 03 -24 55 sum = 6
Input / Output 
Input: nums = [3, -7, 6, 0, -2, 5],
       [sum_range(0, 3), sum_range(2, 4),
        sum_range(2, 2)]
Output: [2, 4, 6]

Constraints: nums contains at least one element; each sum_range queries a valid range. nums 至少有一个元素；每次查询的区间都合法。

直觉：先预处理 / Intuition: preprocess

朴素做法每次调用都把 nums[i..j] 逐个相加，单次 O(n)，q 次查询共 O(nq)。但数组在查询前就已知，所以可以提前把「从 0 开始的累加和」存成一张表。The naive approach sums nums[i..j] on every call — O(n) each, O(nq) in total. Since the array is known beforehand, store the running sums from index 0 ahead of time.

prefix_sum[k] = nums[0] + nums[1] + … + nums[k]
nums       = [ 3  -7  6  0  -2  5 ]
prefix_sum = [ 3  -4  2  2   0  5 ]

对本题数据，prefix_sum[3] = 3 + (-7) + 6 + 0 = 2，恰好覆盖区间 [0, 3]——从 0 开始的查询已经会了。prefix_sum[3] already answers sum_range(0, 3).

为什么可行 / Why it works

前缀和数组里的每一项都是「从 0 开始」的区间和，而查询区间 [i, j] 一般不从 0 开始：把它向前补到 0，再减去多算的那一段即可。Every prefix entry sums a range that starts at 0. Stretch the query range back to 0, then subtract the extra part.

sum_range(0, j) = prefix_sum[j]                          # i == 0，直接读取
sum_range(i, j) = prefix_sum[j] - prefix_sum[i - 1]      # i > 0，减去补上的前缀

减去的部分 nums[0..i-1] 就是 prefix_sum[i-1]（斜线区域），剩下的灰色部分正好是 nums[i..j]。The hatched part nums[0..i-1] is prefix_sum[i-1]; what remains is exactly nums[i..j].

边界情况 / Edge cases

i = 0 · 起点为 0

i - 1 会越界，不能套用减法公式，所以代码用 if i == 0 单独返回 prefix_sum[j]。

i = j · 单元素区间

区间只剩 nums[i]： prefix_sum[i] - prefix_sum[i-1] = nums[i]，公式依然成立（见查询 3）。

负数元素

前缀和不一定递增（本例中 2 之后是 0），但减法恒等式与正负无关，任意整数数组都精确成立。

查询次数 q 很大

朴素法 O(nq)；前缀和是 O(n) 预处理 + 每次 O(1)，总计 O(n + q)，查询越多越划算。

复杂度 / Complexity

Time · 构造 O(n)，查询 O(1)

构造函数填满长度为 n 的 prefix_sum 数组，耗时 O(n)；sum_range 只读 1–2 个元素，耗时 O(1)。

Space · O(n)

额外空间就是 prefix_sum 数组本身。
