Local Maxima in Array · 寻找局部极大值

A local maxima is a value strictly greater than both immediate neighbors; an element is always considered greater than a neighbor outside the array, so an endpoint only needs to beat its one in-bounds neighbor. Return the index of any local maxima in nums = [1, 4, 3, 2, 3] → output 1 (index 4 is also acceptable). Constraint: no two adjacent elements are equal. 局部极大值是严格大于两个直接邻居的值；数组外的邻居一律视为更小，所以端点只需赢过它在数组内的那个邻居。返回任意一个局部极大值的下标：nums = [1, 4, 3, 2, 3] → 输出 1（返回下标 4 也合法）。约束：相邻元素互不相等。

Final Python / 最终代码

def local_maxima_in_array(nums: List[int]) -> int:    left, right = 0, len(nums) - 1    while left < right:        mid = (left + right) // 2        if nums[mid] > nums[mid + 1]:            right = mid        else:            left = mid + 1    return left

下降段保留 mid（它自己就是候选）；上升段排除 mid（nums[mid] < nums[mid + 1] 已证明它不是极大值）。/ A descending pair keeps mid as a candidate; an ascending pair safely drops it.

直觉：山坡必会封顶 / Intuition: every climb must crest

挨个比较每个元素和它的邻居是 O(n) 的线性做法，不算差；但这道题藏着两个更有力的条件：任意一个极大值都算对，且极大值必然存在——相邻元素不相等意味着地形没有平台，沿数组走不是在上坡就是在下坡，必然出现过峰（端点只跟一侧比，天然占优）。于是不必找到「那个」极大值，只要每次都朝「肯定有极大值」的一侧收窄。/ A linear neighbor scan is O(n), but two stronger facts hide in the statement: any maxima is acceptable, and a maxima always exists — no equal neighbors means no flat shelf, so the terrain always crests. We only ever narrow toward the side that must contain one.

情况一 · 下降段 ↘ nums[mid] > nums[mid+1]
if nums[mid] > nums[mid + 1]: right = mid

mid 已经大于右邻居：若 nums[mid-1] 更小，mid 自己就是极大值；若更大，峰在更左边。两种可能都落在 [left, mid]，所以 mid 必须保留，右边界收到 mid。/ mid already beats its right neighbor; if nums[mid-1] is smaller then mid is the maxima, otherwise one hides further left. Both cases live in [left, mid], so mid stays.

情况二 · 上升段 ↗ nums[mid] < nums[mid+1]
else: left = mid + 1

山坡向上必会封顶：一路升到 right 端点（端点只跟一侧比，算赢），或在某处由升转降（转折即峰）——峰一定在 mid 右侧。而 nums[mid] < nums[mid+1] 已证明 mid 自己不是，排除它很安全。/ An ascending slope must crest somewhere to the right — either at the right endpoint or at a rise-to-fall turn. And since nums[mid] already lost to its neighbor, dropping mid is safe.

为什么这样收缩不会漏 / Why the narrowing never misses

  1. 极大值必存在：把数组画成地形线，无相邻相等 ⇒ 每一步严格上升或严格下降。从左端出发沿地形走，要么中途由升转降（转折点就是峰），要么一路升到底——端点只跟数组内的邻居比较，天然算赢。所以峰一定有，二分才有意义。/ A maxima always exists: with no equal neighbors every step is strictly up or strictly down, so walking the terrain from the left either turns from rise to fall (the turn is a peak) or climbs all the way to an endpoint, which only compares against one in-bounds neighbor.
  2. 循环不变量：每次进入循环时，当前区间 [left, right] 必含至少一个局部极大值。初始时成立（整个数组必有峰）；之后每一轮按下面的规则收缩，都不把这个峰抛弃。/ Loop invariant: when the loop body starts, the current range [left, right] contains a maxima. It holds initially, and neither narrowing rule below can throw the peak away.
  3. 下降段保留 mid：mid 大于右邻居，它可能自己就是峰（当 nums[mid-1] 更小时），所以右边界只能收到 mid 而不能是 mid - 1——收过头会把答案丢掉。/ A descending pair keeps mid: mid might itself be the maxima (when nums[mid-1] is smaller), so right may only move to mid, never mid - 1.
  4. 上升段排除 mid：nums[mid] < nums[mid+1] 说明 mid 严格小于一个邻居，绝不可能是极大值，所以左边界可以直接越过它到 mid + 1。/ An ascending pair drops mid: nums[mid] already lost to a neighbor, so it can never be the maxima and left may safely jump to mid + 1.
  5. 收敛：每轮至少排除一半候选下标，O(log n) 轮后必有 left == right；配合不变量，这个唯一剩下的下标就是局部极大值。/ Convergence: each round discards at least half the candidates, so left == right after O(log n) rounds; the invariant makes that single index a maxima.

边界情况 / Edge cases

峰在最开头 · 严格递减

每个 mid 都落在下降段，right 一路左移，最终收在 0。/ Every midpoint forms a descending pair, so right marches left until the answer is index 0.

峰在最末尾 · 严格递增

每个 mid 都落在上升段，left 一路右移，最终收在 n - 1。/ Every midpoint forms an ascending pair, so left marches right to the last index.

单元素数组

while 0 < 0 一开始就不成立，直接返回 0——它在外侧的邻居被视为更小。/ while 0 < 0 fails immediately, so the single element's index 0 is returned; its out-of-bounds neighbors count as smaller.

多个极大值

任意一个峰都合法；二分走到哪个取决于 mid 的落点，本例返回 1。/ Any peak is a valid answer; which one binary search finds depends on where mid lands — here it returns 1.

复杂度 / Complexity

Time · O(log n)

与经典二分同构：每轮取一次中点、比较一对邻居、把候选区间缩小约一半。/ One midpoint, one neighbor comparison, and roughly half the candidates per round — the same shape as classic binary search.

Extra space · O(1)

只保存 left、mid、right 三个下标；数组 nums 从不修改。/ Only three index variables are stored; nums is never modified.
