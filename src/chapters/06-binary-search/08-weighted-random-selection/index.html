Weighted Random Selection · 按权重随机选择

Given items with weights, implement random selection where P(index i) = weights[i] / sum(weights). Example: weights = [3, 1, 2, 4] has sum = 10, so index 0 is returned about 30% of the time. Return the selected index. 给定一组带权重的 items，实现随机选择：选到下标 i 的概率 P(i) = weights[i] / sum(weights)。例：weights = [3, 1, 2, 4]，sum = 10，下标 0 大约以 30% 的概率被选中。返回被选中的下标。

完整 Python 代码

class WeightedRandomSelection:    def __init__(self, weights: List[int]):        self.prefix_sums = [weights[0]]        for i in range(1, len(weights)):            self.prefix_sums.append(self.prefix_sums[-1] + weights[i])     def select(self) -> int:        # Pick a random target between 1 and the largest possible endpoint.        target = random.randint(1, self.prefix_sums[-1])        left, right = 0, len(self.prefix_sums) - 1        # Perform lower-bound binary search to find which endpoint (i.e.,        # prefix sum value) corresponds to the target.        while left < right:            mid = (left + right) // 2            if self.prefix_sums[mid] < target:                left = mid + 1            else:                right = mid        return left

把概率摊成一条数轴 · Lay probability on a number line

所有概率的分母都是 sum(weights)。把数轴上的整数 1..sum(weights) 按权重切成 n 段：段 i 的长度就是 weights[i]。在数轴上均匀取一个数，它落入段 i 的概率恰好是 weights[i] / sum(weights)——这正是题目要求的分布。 / All probabilities share the denominator sum(weights), so split the number line 1..sum(weights) into segments of length weights[i]; a uniform pick lands in segment i with exactly the desired probability.

weights = [1, 4] · sum = 5

取到数字 k 就返回它所在的段。段越长（权重越大），被取中的概率越大——但取数本身永远是均匀的。 / Picking number k means returning its segment; the pick is uniform, the segment sizes create the bias.

weights = [3, 1, 2, 4] · sum = 10 · 端点即前缀和

段 i 的端点 = 前面所有段长 + 本段长 = weights[0] + … + weights[i]。把每个数字→下标存进哈希表要 O(sum) 空间；只存 n 个端点只要 O(n)，而且端点天然有序。 / Endpoint i is the prefix sum weights[0..i]; storing n sorted endpoints beats an O(sum) hash map of every number.

第一个 ≥ target 的端点 · The first endpoint ≥ target

target 落在段 i，等价于「段 i 的端点是第一个 ≥ target 的端点」。端点在 target 左侧的一定属于更早的段；而第一个 ≥ target 的端点再往右，就已经是别的段了。所以答案 = 下界（lower bound）。 / A number belongs to the segment whose endpoint is the first one ≥ target: endpoints left of the target belong to earlier segments.

  1. prefix_sums 单调不减（权重为正），所以「第一个 ≥ target」可以用下界二分查找，每轮排除一半。 / prefix_sums is non-decreasing, so the first endpoint ≥ target is a lower-bound binary search.
  2. prefix_sums[mid] < target → mid 及其左侧全部排除，left = mid + 1；否则 mid 本身是候选，right = mid 保留它。 / If prefix_sums[mid] < target, mid belongs to an earlier segment; otherwise keep mid as the candidate.
  3. left == right 时只剩一个候选端点，它的下标就是答案。 / When left == right, the single remaining candidate endpoint is the answer.

为什么 randint 的范围是 1..sum · Why the bounds are 1..sum

1..sum 一个不多 · Exactly the numbers on the line

数轴上的数字是 1..sum(weights) 共 sum 个整数，每个整数恰好占一个单位长度；取到 0 或 sum+1 会落在所有段之外。random.randint 两端都含，所以 sum 本身也能取到——它属于最后一段。 / The line holds exactly the integers 1..sum; randint is inclusive, so sum itself is reachable and belongs to the last segment.

target 每次都不一样 · A fresh target per call

每次调用 select() 都重新 randint。本页动画把书中的示例固定为 target = 5，好让每一步可复现；刷新页面会重放同一段演示。 / Each select() call draws a fresh target; the trace fixes the book's example target = 5 so every step is reproducible.

边界情况 · Edge cases

某个权重独占鳌头 · One dominant weight

一个段几乎铺满整条数轴：大多数 target 落进它，命中概率本就接近 1——这是分布的如实体现，不是错误。二分查找依旧 O(log n)。 / A dominant segment covers nearly the whole line; the bias is the intended distribution, and the search stays O(log n).

单个元素 · Single item

n = 1 时 left == right == 0，while 循环直接跳过，返回 0；randint(1, weights[0]) 取到什么都是它。 / With n = 1 the loop is skipped and select returns 0.

target 恰好等于端点 · Target equals an endpoint

target = 4 → 端点 4 满足 ≥ target，属于段 1 而非段 2。若条件写成 > 就会把 4 错划给下一段——>= 是关键。 / A target equal to an endpoint belongs to that segment; the ≥ condition is what makes this work.

复杂度 · Complexity

__init__ · O(n) 时间 / O(n) 空间

一次遍历累加出 prefix_sums；数组本身占 O(n) 空间，比存 O(sum) 个数字的哈希表省得多。 / One pass builds the prefix sums; storing n endpoints costs O(n) space.

select · O(log n) 时间 / O(1) 空间

在排好序的端点数组上做下界二分，每轮减半；只用到 left、right、mid 三个变量。 / A lower-bound binary search over the sorted endpoints uses O(log n) time and O(1) extra space.
