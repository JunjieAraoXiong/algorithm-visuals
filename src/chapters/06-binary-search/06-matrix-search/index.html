Matrix Search · 搜索二维矩阵

Each row of matrix is sorted in non-decreasing order, and the first value of each row is greater than or equal to the last value of the previous row — read in flattened order, the whole matrix is one continuous sorted sequence. Determine whether target exists in it. The trace below uses matrix = [[2, 3, 4, 6], [7, 10, 11, 17], [20, 21, 24, 33]] with target = 21 (found), then a second pass with target = 0 (absent). 矩阵的每一行按非递减顺序排列，且每行第一个值 ≥ 上一行最后一个值——按行优先展开，整个矩阵就是一段连续的升序序列。判断 target 是否存在。下方演示先用 matrix = [[2, 3, 4, 6], [7, 10, 11, 17], [20, 21, 24, 33]]、target = 21（能找到），再走一遍 target = 0（不存在）。

Final Python / 最终代码

def matrix_search(matrix: List[List[int]], target: int) -> bool:    m, n = len(matrix), len(matrix[0])    left, right = 0, m * n - 1    # Perform binary search to find the target.    while left <= right:        mid = (left + right) // 2        r, c = mid // n, mid % n        if matrix[r][c] == target:            return True        elif matrix[r][c] > target:            right = mid - 1        else:            left = mid + 1    return False

移动 chip 只改变下标变量（left、right、mid 以及由 mid 映射出的 r、c）；矩阵本身从不被修改。/ Moving a chip changes only index variables; the matrix is never modified.

下标映射：不构造扁平数组 / Index mapping without flattening

逐个格子线性扫描是 O(m·n)，完全没有用到「有序」。把矩阵复制成一个扁平数组再二分，则要 O(m·n) 的时间和空间来构建——得不偿失。关键观察是：按行优先展开，矩阵本来就是一段升序序列，每个格子早已有一个「隐式」的扁平下标。只要能在下标 i 和格子 (r, c) 之间互相换算，就不需要真的扁平化。/ A linear scan costs O(m·n) and ignores the sorted property; materializing a flattened array costs O(m·n) time and space. Read row by row, the matrix already is one ascending sequence — every cell already has an implicit flat index. Mapping between i and (r, c) removes the need to flatten at all.

在扁平数轴上二分 / Binary search on the flat number line

搜索空间就是这条 0 … m·n−1 的数轴：left = 0、right = m·n−1。每轮取 mid = (left + right) // 2，用 r = mid // n、c = mid % n 映射回格子，比较 matrix[r][c] 与 target：相等即返回；中点值偏大则 right = mid − 1，偏小则 left = mid + 1。下方是 target = 21 的完整路线。/ The search space is the number line 0 … m·n−1. Each round halves it: compute mid, map it back to a cell, compare, and narrow to one side. The full route for target = 21:

target = 21 的中点路线 / The midpoint route
mid = 5 → cell (1, 1) = 10 < 21 → left = mid + 1 = 6 mid = 8 → cell (2, 0) = 20 < 21 → left = mid + 1 = 9 mid = 10 → cell (2, 2) = 24 > 21 → right = mid - 1 = 9 mid = 9 → cell (2, 1) = 21 == 21 → return True
退出条件：while left <= right / The exit condition

第 4 轮时 left == right == 9，区间只剩一格；正是 <= 让循环继续，检查这最后一格并命中。若写成 left < right，单格空间会被直接跳过，target 明明在矩阵里也会返回 False。/ Round 4 keeps left == right == 9: a one-cell space. Only <= enters the loop and examines that last cell; with < a target sitting in a single-cell space would be missed.

为什么这样收缩不会漏 / Why the narrowing never misses

  1. 按扁平下标读，值单调不减：i < j ⇒ flat[i] ≤ flat[j]。这是「每行有序 + 每行开头 ≥ 上行末尾」的直接推论。/ Flattened values are non-decreasing: i < j ⇒ flat[i] ≤ flat[j], exactly what the row rules guarantee.
  2. matrix[r][c] > target 时，下标大于 mid 的值全部 ≥ matrix[r][c] > target，右侧（含 mid）可以整段丢弃；right = mid − 1。/ When the midpoint value exceeds target, everything to its right is at least as large — discard it safely with right = mid − 1.
  3. matrix[r][c] < target 时对称：下标小于 mid 的值全部 ≤ matrix[r][c] < target，左侧（含 mid）丢弃；left = mid + 1。/ Symmetrically, a smaller midpoint value discards the left side with left = mid + 1.
  4. 不变量「target 若存在，必在 [left, right] 内」每轮保持；区间每轮至少折半，所以 O(log(m·n)) 轮内必然定论。/ The invariant “target, if present, lies in [left, right]” is preserved each round while the space at least halves.

边界情况 / Edge cases

比所有值小 · target = 0

上方「查找 0」场景逐步演示了这条路径：mid 依次 5、2、0，对应值 10、4、2 全部 > 0，right 一路 11 → 4 → 1 → −1；循环以 0 ≤ −1 不成立结束，返回 False。/ Every midpoint is too large, so right marches left past 0 until the space is empty.

比所有值大 · target = 100

对称的另一端：mid 依次 5、8、10、11，值 10、20、24、33 全部 < 100，left 一路 6 → 9 → 11 → 12；12 ≤ 11 不成立，返回 False。/ Symmetric: every midpoint is too small, left marches right past 11, and the loop exits empty-handed.

只剩一格 · left == right

「查找 21」第 4 轮：left == right == 9，mid = 9，单格空间仍被检查并命中。循环条件必须是 left <= right。/ The last round of the found trace checks the single remaining cell — that is why the condition uses <=.

重复值 · duplicates

题目只保证非递减，相等的值可以相邻：== target 分支先命中；> 分支丢弃的右侧全部 ≥ 当前值，< 分支同理——重复值不影响判断。/ Duplicates are fine: equality is checked first, and each strict comparison discards a side whose values cannot equal target.

复杂度 / Complexity

时间 · O(log(m·n))

搜索空间共 m·n 格，每轮至少折半：一次中点、一次下标映射、一次比较。12 格的示例最多 4 轮即定论。/ The space of m·n cells at least halves each round; the 12-cell example settles in 4 rounds.

空间 · O(1)

只保存 left、right、mid 和映射出的 r、c 几个整数；从不构造扁平数组（那样要 O(m·n) 时间和空间）。/ Only a few indexes are stored; no flattened array is ever built.
