Find the Target in a Rotated Sorted Array · 旋转排序数组中查找目标

An ascending array was rotated at a pivot: a front portion was moved to the end, so [1, 2, 3, 4, 5] may become [3, 4, 5, 1, 2]. Return the index of target in nums = [8, 9, 1, 2, 3, 4, 5, 6, 7], or -1 if it is absent. 升序数组在某个 pivot 处被旋转：开头一段被搬到末尾，例如 [1, 2, 3, 4, 5] 变成 [3, 4, 5, 1, 2]。在 nums = [8, 9, 1, 2, 3, 4, 5, 6, 7] 中返回 target 的下标，不存在则返回 -1。

Final Python / 最终代码

def find_the_target_in_a_rotated_sorted_array(nums: List[int], target: int) -> int:    left, right = 0, len(nums) - 1    while left < right:        mid = (left + right) // 2        if nums[mid] == target:            return mid        # If the left subarray [left : mid] is sorted, check if the        # target falls in this range. If it does, search the left        # subarray. Otherwise, search the right.        elif nums[left] <= nums[mid]:            if nums[left] <= target < nums[mid]:                right = mid - 1            else:                left = mid + 1        # If the right subarray [mid : right] is sorted, check if the        # target falls in this range. If it does, search the right        # subarray. Otherwise, search the left.        else:            if nums[mid] < target <= nums[right]:                left = mid + 1            else:                right = mid - 1     # If the target is found in the array, return it's index. Otherwise,    # return -1.    return left if nums and nums[left] == target else -1

Moving a chip changes only an index variable (left, mid, right); the array nums itself is never modified. / 移动 chip 只改变 left、mid、right 三个下标变量，数组 nums 本身从不被修改。

The rotation / 旋转做了什么

Rotation cuts a sorted array into two ascending runs and joins them tail-to-head. Inspecting every number is a linear O(n) scan; the fact that the array was sorted before rotation is what binary search can still exploit. / 旋转把升序数组切成两段、首尾相接。逐个检查是 O(n) 的线性做法；旋转前有序这个性质，正是二分查找仍然可以利用的东西。

One half is always sorted / 总有一半是有序的

Each midpoint splits the search space into [left : mid] and [mid : right]. A rotation creates only one break, so at most one half contains it — the other half is still ascending. Identify the sorted half, then test whether target falls inside its value range: range [nums[left], nums[mid]] for the left half, [nums[mid], nums[right]] for the right half. The bars under the array make the two slopes visible. / 每个中点把搜索空间切成 [left : mid] 和 [mid : right] 两段。旋转只产生一个断点，至多一段含有断点，另一段仍然升序。先找出有序的那半段，再检查 target 是否落在它的值域里：左半段看 [nums[left], nums[mid]]，右半段看 [nums[mid], nums[right]]。数组下方的条形图让两段斜率一目了然。

Why the narrowing never misses / 为什么这样收缩不会漏

  1. A rotation creates exactly one break, so when mid cuts [left : right] into two halves, at most one half contains the break — the other half is still ascending. / 旋转只产生一个断点；mid 切开搜索空间时，至多一半含断点，另一半必然保持升序。
  2. The sorted half's smallest and largest values are its two endpoints, e.g. [3, 4, 5, 6, 7] spans [3, 7]. / 有序半段的最小值、最大值就在两端，例如 [3, 4, 5, 6, 7] 的值域是 [3, 7]。
  3. All numbers are unique: if target is inside that range it must be in the sorted half; if it is outside, it must be in the other half. / 数组中的数字互不相同：target 落在值域内就必在有序半段，在值域外就必在另一半。
  4. Each round discards at least half of the remaining space, so left and right close in on target in O(log n) rounds. / 每轮至少排除一半元素，left 与 right 用 O(log n) 轮就向 target 收拢。

Edge cases / 边界情况

Both halves sorted / 两半都可能有序

When mid lands inside the untouched run, both halves are sorted. Because nums[mid] == target is checked first, either case gives the correct next step. / 当 mid 落在未被旋转的升序段里时，两段同时有序；由于先检查 nums[mid] == target，两种情况用哪个都正确。

Target absent / target 不存在

The loop ends with left == right; that single index is compared with target, and -1 is returned if unequal. Walk through the 「查找 0」steps above. / 循环以 left == right 收尾，最后一个下标单独与 target 比较，不相等就返回 -1；上方「查找 0」的每一步演示了这条路径。

Why exclude mid / 为什么排除 mid

nums[mid] was already compared with target at the start of the round, so narrowing with mid - 1 / mid + 1 safely removes it from the search space. / nums[mid] 在每轮开头就已与 target 比较过，所以收缩时用 mid - 1 / mid + 1 把它一并排除是安全的。

Complexity / 复杂度

Time · O(log n)

Each round roughly halves the search space: one midpoint, one range test, one narrowing. / 每轮把搜索空间缩小约一半：取一次中点、做一次值域判断、收缩一次。

Extra space · O(1)

Only three indexes (left, mid, right) are stored; nums is never modified. / 只保存 left、mid、right 三个下标，数组本身不被修改。
