Merge Overlapping Intervals · 合并重叠区间

Given intervals = [[3, 4], [7, 8], [2, 5], [6, 7], [1, 4]], merge every overlapping pair so the returned list contains no overlapping intervals.给定一组区间，把所有重叠的区间合并，使结果中任意两个区间都不重叠。

Input:  intervals = [[3, 4], [7, 8], [2, 5], [6, 7], [1, 4]]Output: [[1, 5], [6, 8]]

不变量 / Invariant

A
B
merged
A.end < B.start

完整 Python 代码

def merge_overlapping_intervals(    intervals: List[Interval]) -> List[Interval]:    intervals.sort(key=lambda x: x.start)    merged = [intervals[0]]    for B in intervals[1:]:        A = merged[-1]        # If A and B don't overlap, add B to the merged list.        if A.end < B.start:            merged.append(B)        # If they do overlap, merge A with B.        else:            merged[-1] = Interval(A.start, max(A.end, B.end))    return merged

Interval 用 start / end 两个属性表示；排序按 start 升序，排序后每个区间只被处理一次。

判定规则：两种情况 / Two cases

先看两个区间 A、B（A 先开始）。重叠与否只取决于一个比较：A.end 与 B.start。

A.end < B.start → 不重叠

A ends before B starts, so the two can never overlap.A 在 B 开始之前就已结束，二者不可能重叠，各自保留。

A.end ≥ B.start → 重叠

B starts at or before A ends, so they share at least one point; touching endpoints (A.end == B.start) count.B 在开始不晚于 A 结束时开始，两者至少共享一个点（端点相接也算重叠），需要合并。

要对这个判定放心，需要知道任意两个区间谁先开始——所以第一步按 start 排序。排序之后，每一对相邻区间都是左边先开始，A 与 B 的角色一目了然。

为什么只对 A 比较就够了 / Why one comparison suffices

排序后依次处理，A = merged[-1]。merged 中的区间互不重叠且按 start 有序，而且每个合并后的区间右端点覆盖了它吸收的所有区间。因此若 B.start > A.end，B 与 merged 中更早的区间也不可能重叠，直接追加；若 B.start ≤ A.end，把 A 的右端点延伸到 max(A.end, B.end) 即覆盖 B。每个区间只被处理一次，单趟扫描即可。

  • 合并区间的起点总是 A.start（排序保证 A 先开始），终点取 max(A.end, B.end)——B 完全包含于 A 时终点不变。
  • merged[-1] = Interval(A.start, max(A.end, B.end)) 更新的是 merged 里的存储值，B 本身没有被修改。

边界情况 / Edge cases

只有一个区间

merged = [intervals[0]]，循环不执行，直接返回。输入至少一个区间，因此 intervals[0] 一定存在。

完全不重叠

每个 B 都触发 merged.append(B)，merged 长度等于 n，顺序即排序后的顺序。

端点相接

A.end == B.start 时 A.end < B.start 为 False，按重叠处理：例如 [6, 7] 与 [7, 8] 合并为 [6, 8]。

B 完全包含于 A

max(A.end, B.end) = A.end，合并后区间不变（如 [1, 5] 吸收 [3, 4]）。

复杂度 / Complexity

Time · O(n log n)

dominated by the sort O(n log n); the single pass over the intervals is O(n).时间由排序的 O(n log n) 主导，之后的单趟扫描是 O(n)。

Extra space · O(n)

The merged output list holds up to n intervals; the sort is in place.输出列表 merged 最多存放 n 个区间；排序原地进行。
