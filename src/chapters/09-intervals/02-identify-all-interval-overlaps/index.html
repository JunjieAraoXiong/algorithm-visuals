Identify All Interval Overlaps · 找出所有区间重叠

Return an array of all overlaps between two arrays of intervals, intervals1 and intervals2. Each individual interval array is sorted by start value, and contains no overlapping intervals within itself.返回 intervals1 与 intervals2 之间所有重叠的区间。两个数组各自按起点升序，且内部没有重叠区间。

Input:  intervals1 = [[1, 4], [5, 6], [9, 10]]        intervals2 = [[2, 7], [8, 9]]Output: [[2, 4], [5, 6], [9, 9]]

不变量 / Invariant

i, j
A
B
overlaps

完整 Python 代码

def identify_all_interval_overlaps(    intervals1: List[Interval], intervals2: List[Interval]) -> List[Interval]:    overlaps = []    i = j = 0    while i < len(intervals1) and j < len(intervals2):        # Set A to the interval that starts first and B to the other        # interval.        if intervals1[i].start <= intervals2[j].start:            A, B = intervals1[i], intervals2[j]        else:            A, B = intervals2[j], intervals1[i]        # If there's an overlap, add the overlap.        if A.end >= B.start:            overlaps.append(Interval(B.start, min(A.end, B.end)))        # Advance the pointer associated with the interval that ends        # first.        if intervals1[i].end < intervals2[j].end:            i += 1        else:            j += 1    return overlaps

书中印刷的 len(intervalvals2) 是笔误，正确写法为 len(intervals2)，本页按正确版本实现。终点完全相同时走 else 移动 j。

问题要点 / Problem

两个数组各自有序、内部互不重叠，所以任何重叠必然发生在一个来自 intervals1、一个来自 intervals2 的区间之间。约束：每个区间满足 start < end。

直觉：先会求两个区间的重叠 / One overlap, two intervals

设 A 先开始。两区间重叠 ⟺ A.end ≥ B.start；重叠段从较晚的起点 B.start 开始，到较早的终点 min(A.end, B.end) 结束。

B 超出 A 的右端：重叠到 A.end 为止 → [B.start, A.end]。

B 完全落在 A 内部：重叠到 B.end 为止 → [B.start, B.end]。

  1. 设 A 为起点较早的区间，B 为另一个区间。每轮先比较两个当前区间的起点。
  2. 若 A.end ≥ B.start，记录重叠 [B.start, min(A.end, B.end)]。否则什么都不记录。
  3. 移动结束较早的区间对应的指针，直到某个指针越过数组末尾。之后不会再有新的重叠。

为什么正确 / Why it works

两个数组都按起点升序。若 intervals1[i].end < intervals2[j].end，则 intervals1[i] 不可能再和 intervals2 中 j 之后的任何区间重叠——后面的区间起点更晚，而 intervals1[i] 早已结束。所以移动 i 不会丢解；对称地，移动 j 也不会。每次记录的都是两区间交集 [B.start, min(A.end, B.end)]，不漏不重。

判断谁先结束时用的是 intervals1[i] 和 intervals2[j]，而不是 A、B——因为无法事先知道 A、B 各属于哪个数组。

边界情况 / Edge cases

端点相接 · Touching endpoints

[8, 9] 与 [9, 10] 在 9 处相接：A.end ≥ B.start 取等号仍算重叠，记录零宽度区间 [9, 9]。它的起点和终点相同，在 overlaps 行里画成一个点。

完全不重叠 · Disjoint pair

[2, 7] 与 [9, 10] 之间有空隙：不记录，照样移动结束较早一方的指针。

终点相同 · Equal ends

intervals1[i].end == intervals2[j].end 时条件 < 不成立，走 else 移动 j；每轮必有一个指针前进，不会死循环。

空数组 · Empty input

任一数组为空时循环一次也不执行，直接返回 []。

复杂度 / Complexity

Time · O(n + m)

n、m 分别是 intervals1、intervals2 的长度；两个数组各被遍历一次，每个区间只被指针访问一遍。

Extra space · O(1)

只使用 i、j、A、B 几个变量；输出数组 overlaps 不计入额外空间。
