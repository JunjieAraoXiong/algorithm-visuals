Largest Overlap of Intervals · 区间最大重叠数

Given intervals = [[1, 3], [2, 6], [4, 8], [6, 7], [5, 7]], find the maximum number of intervals that overlap at any point. Each interval is half-open [start, end): the start is included, the end is excluded.给定区间数组 intervals，求任意时刻最多有多少个区间重叠。区间是半开的 [start, end)：包含起点，不包含终点。

不变量 / Invariant

active_intervals
max_overlaps
当前点 / point
已处理 / processed

完整 Python 代码

def largest_overlap_of_intervals(intervals: List[Interval]) -> int:    points = []    for interval in intervals:        points.append((interval.start, 'S'))        points.append((interval.end, 'E'))    # Sort in chronological order. If multiple points occur at the same    # time, ensure end points are prioritized before start points.    points.sort(key=lambda x: (x[0], x[1]))    active_intervals = 0    max_overlaps = 0    for time, point_type in points:        if point_type == 'S':            active_intervals += 1        else:            active_intervals -= 1        max_overlaps = max(max_overlaps, active_intervals)    return max_overlaps

排序键 (x[0], x[1]) 先比时间再比类型。ASCII 中 'E' < 'S'，所以同一时刻的 'E' 自动排在 'S' 前面，无需额外判断。

问题 / Problem

The answer is a single number: the largest count of intervals covering one point.答案是一个数：覆盖同一个点的区间个数的最大值。

Input

intervals = [[1, 3], [2, 6], [4, 8], [6, 7], [5, 7]]

Output3

The maximum overlap occurs on [5, 6), covered by [2, 6), [4, 8) and [5, 7).三个区间在 [5, 6) 上同时生效。

图中区间左端的方形实帽表示起点（包含），右端的空心圆表示终点（排除）——这是半开区间 [start, end) 的记号。

直觉：活跃区间 / Active intervals

x intervals overlap at a point ⇔ exactly x intervals are active there: started at or before this time, not yet ended. At time 5, [2, 6), [4, 8), [5, 7) are active — 3 overlapping intervals.某点有 x 个区间重叠 ⇔ 恰有 x 个区间在此处“活跃”：已经开始、尚未结束。例如时刻 5 有 [2, 6)、[4, 8)、[5, 7) 三个活跃区间。

A start point means one more active interval (+1); an end point means one just finished (−1). Sweeping the time axis while applying these updates yields the overlap count at every event point.起点 ⇒ 活跃数 +1；终点 ⇒ 活跃数 −1。沿时间轴扫过所有端点并应用这些更新，就得到每个事件点处的重叠数。

扫描线：端点排序 / Sweep over sorted points

Combine all 2n start/end points into one array and sort it. Between two consecutive event points the set of active intervals never changes, so the maximum overlap is always attained at an event point — recording the largest active_intervals during the sweep is enough.把 2n 个起终点混进一个数组排序。相邻事件点之间活跃集合不变，所以最大值一定在某个事件点处取到——扫描时记录 active_intervals 的历史最大值即可。

边界情况：同时刻的端点 / Concurrent points

Right before time 6, active_intervals = 3. At 6, the end of [2, 6) and the start of [6, 7) coincide. Which one is processed first?刚到 6 之前 active_intervals = 3。在 6 处，[2, 6) 的终点与 [6, 7) 的起点同时出现，先处理哪个？

Half-open intervals never overlap at a shared boundary: [2, 6) and [6, 7) are disjoint. The sort key (x[0], x[1]) compares the type strings in ASCII order ('E' < 'S'), so end points are naturally prioritized before start points — no extra branch is needed.半开区间在共享边界处不相交：[2, 6) 与 [6, 7) 没有公共点。排序键 (x[0], x[1]) 按 ASCII 比较类型（'E' < 'S'），终点自然排在起点前，不需要额外分支。

复杂度 / Complexity

Time · O(n log n)

We build a points array of size 2n and sort it (O(n log n)), then iterate over it once (O(n)).排序 2n 个端点 O(n log n)，之后的线性扫描 O(n)。

Extra space · O(n)

The points array holds 2n entries.额外空间来自 points 数组，共 2n 项。
