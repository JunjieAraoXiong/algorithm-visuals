Shift Zeros to the End · 移动零到末尾

Modify nums = [0, 1, 0, 3, 2] in place so every zero moves to the end while the non-zero values keep their relative order.原地修改数组，把所有零移到末尾，同时保持非零元素的相对顺序。

Final Python / 最终代码

def shift_zeros_to_the_end(nums: list[int]) -> None:    left = 0    for right in range(len(nums)):        if nums[right] != 0:            nums[left], nums[right] = nums[right], nums[left]            left += 1    return None

The swap writes two array positions. Moving left or right changes only a variable reference. / 交换会写入两个数组位置；移动指针只改变变量引用。

Focus on non-zero values / 只搬运非零元素

Instead of searching for zeros and pushing them right, let left mark the next position that should receive a non-zero value. right scans every item exactly once.

Input / 输入
01032
non-zero order = 1 → 3 → 2
Output / 输出
13200
same order = 1 → 3 → 2

Why the order stays stable / 为什么顺序不会改变

  1. right reads values from left to right.
  2. Every non-zero value is placed at the current left position.
  3. left advances only after a non-zero value is placed.
  4. Therefore non-zero values are written in the same order in which they are found.

Edge cases / 边界情况

[0, 0, 0]

left never moves; the array is already correct. / 没有非零元素，left 不移动。

[1, 3, 2]

Each value swaps with itself, preserving the array. / 每个元素与自身交换，数组保持不变。

Complexity / 复杂度

Time · O(n)

right visits each index once.

Extra space · O(1)

The mutation is in place; only two indexes are stored.
