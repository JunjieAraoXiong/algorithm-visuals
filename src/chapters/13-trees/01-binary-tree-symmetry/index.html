Binary Tree Symmetry · 二叉树对称性

Determine if a binary tree is vertically symmetric. That is, the left subtree of the root node is a mirror of the right subtree. Example: [1, 2, 2, 3, 4, 4, 3] → True.判断一棵二叉树是否关于根节点的竖直轴对称：根节点的左子树是右子树的镜像。镜像 = 把树翻转（每个节点的左右孩子互换）后，右子树与左子树完全重合。书例：树 [1, 2, 2, 3, 4, 4, 3] 对称，输出 True。

完整 Python 代码

def binary_tree_symmetry(root: TreeNode) -> bool:    if not root:        return True    return dfs(root.left, root.right)def dfs(node1: TreeNode, node2: TreeNode) -> bool:    # Base case: if both nodes are null, they're symmetric.    if not node1 and not node2:        return True    # If one node is null and the other isn't, they aren't symmetric.    if not node1 or not node2:        return False    # If the values of the current nodes don't match, trees aren't symmetric.    if node1.val != node2.val:        return False    # Compare the 'node1's left subtree with 'node2's right subtree. If these    # aren't symmetric, the whole tree is not symmetric.    if not dfs(node1.left, node2.right):        return False    # Compare the 'node1's right subtree with 'node2's left subtree.    return dfs(node1.right, node2.left)

橙色 = 当前比较的镜像对（弧线连接 node1 与 node2）；红色 = 判定失败的对；虚线圆 null = 不存在的节点；竖直虚线 = 对称轴。树形布局帧间固定，只有高亮随步骤移动。

直觉：镜像 = 翻转后重合 / Mirror = flipped copy

根节点自己不影响对称性——它坐在对称轴上，左右怎么比都是它自己。所以 binary_tree_symmetry 判掉空树之后，直接把 root.left 与 root.right 交给 dfs。真正的问题是：左子树是不是右子树翻转后的样子。翻转即每个节点的左右孩子互换，因此镜像位置上的节点一一对应：左子树某节点的左孩子，对应右子树镜像节点的右孩子。

于是 dfs(node1, node2) 只回答一件事：以 node1 为根的子树，是否是 node2 为根的子树的镜像？它同步向下走两棵树——node1 向左时 node2 向右，node1 向右时 node2 向左——任何一对节点不符，整棵树就不是对称的。

三种判定 / Three verdicts

每一对镜像节点只有三种结局，前两条都发生在“访问孩子之前”——这就是面试里常说的：用属性前先判空。

都 null → True

if not node1 and not node2: return True。两边同时没有节点，结构上互相镜像。叶子节点的孩子比较总会走到这里。

一个 null → False

if not node1 or not node2: return False。一边有一边没有，形状已经不同——哪怕值全都相等。反例 [1,2,2,null,3,null,3] 就是死在这一条。

值不等 → False

if node1.val != node2.val: return False。镜像位置上的值必须相等；节点都存在但 2 对 3，立即失败。

都相等 → 递归两对镜像孩子

先 dfs(node1.left, node2.right)，左镜像对返回 False 就提前 return False；否则 return dfs(node1.right, node2.left)。注意两对是“交叉”的——同侧的孩子互不比较。

边界情况 / Edge cases

空树 → True

if not root: return True。约定空树对称；这也是代码里唯一的根特判，之后全部交给 dfs。

单节点树 → True

根非空，进入 dfs(null, null)：左右孩子都不存在，命中“都 null → True”。

值全等也可能 False

[1,2,2,null,3,null,3] 里 1,2,2,3,3 全都成对相等，但左 2 缺左孩子、右 2 有右孩子——结构不镜像，照样输出 False。

面试提示：判空先于取属性

dfs 里先判两个 null，才去碰 node1.val、node1.left。对空节点取属性是这类题最常见的崩溃点。

复杂度 / Complexity

Time · O(n)

每个节点至多被比较一次（成对进入 dfs 一次），每次比较只做常数次判断，合计 O(n)。

Space · O(h)

递归栈深度等于树高 h（dfs 的 node1/node2 各沿一条链向下）。平衡树 O(log n)；最坏情况树退化成链，h = n，空间 O(n)。
