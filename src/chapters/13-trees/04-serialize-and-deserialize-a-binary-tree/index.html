Serialize and Deserialize a Binary Tree · 二叉树的序列化与反序列化

Write a function to serialize a binary tree into a string, and another function to deserialize that string back into the original binary tree structure. Example: root 5, left child 3 (with 1, 4), right child 9 (with left child 6) → "5,3,1,#,#,4,#,#,9,6,#,#,#".题目：把一个二叉树 serialize（序列化）成一个字符串，再 deserialize（反序列化）还原出原来的树。书例：根 5，左孩子 3（子节点 1、4），右孩子 9（左孩子 6）；用前序遍历 + '#' 空标记写出的串是 "5,3,1,#,#,4,#,#,9,6,#,#,#"。

def serialize(root: TreeNode) -> str:    # Perform a preorder traversal to add node values to a list, then convert the    # list to a string.    serialized_list = []    preorder_serialize(root, serialized_list)    # Convert the list to a string and separate each value using a comma    # delimiter.    return ','.join(serialized_list)# Helper function to perform serialization through preorder traversal.def preorder_serialize(node, serialized_list) -> None:    # Base case: mark null nodes as '#'.    if node is None:        serialized_list.append('#')        return    # Preorder traversal processes the current node first, then the left and    # right children.    serialized_list.append(str(node.val))    preorder_serialize(node.left, serialized_list)    preorder_serialize(node.right, serialized_list)def deserialize(data: str) -> TreeNode:    # Obtain the node values by splitting the string using the comma delimiter.    node_values = iter(data.split(','))    return build_tree(node_values)# Helper function to construct the tree using preorder traversal.def build_tree(values: List[str]) -> TreeNode:    val = next(values)    # Base case: '#' indicates a null node.    if val == '#':        return None    # Use preorder traversal processes the current node first, then the left and    # right children.    node = TreeNode(int(val))    node.left = build_tree(values)    node.right = build_tree(values)    return node

树固定为上方示例树。序列化帧高亮 serialize 一侧的代码，反序列化帧高亮 build_tree 一侧；下方字符串面板里，节点值用实线格、'#' 用灰色虚线格。

直觉：前序写、前序读 / Preorder write, preorder read

序列化方式决定 deserialize 能否唯一重建。选前序：写出的第一个 token 就是根，读回时同样先拿到根——写入与读取天然同步。只存节点值却不够（书 p.102 的歧义）：根 5 之后出现 9 时，串里看不出它是左孩子还是右孩子，同一个串可对应多棵树。

补上空孩子标记后歧义消失：每个空位置用 '#' 占位，每个节点恰好贡献「值，左，右」三段，串与树一一对应。反序列化只需一个游标按前序消费列表：取到 '#' 返回 None，否则建节点、递归建左右。

前序：首尾都是根 / First token is the root

serialize 从根出发先写自己；deserialize 的第一个值也必须是根。顺序一致让重建不需要任何回溯查找，一次线性扫描即可完成。

'#' 的代价：2n+1 个 token / Null markers

n 个节点的二叉树恰好有 n+1 个空孩子指针（对子树归纳可证），所以串长 2n+1。'#' 就是把这些空位置显式记下来——用长度换唯一性。

Follow-up：四种遍历都行吗 / Which traversals work

前序 Preorder · 可行（本页）

首值即根，先建根再递归左右。写入与读取完全同序，最直观。

后序 Postorder · 可行

根在串尾：倒着读串，先建右子树、再建左子树，最后建根。顺序与本页镜像。

中序 Inorder · 困难

根的位置无法从串里推出：拿到 "1,5,9" 时分不清 5 的左右边界在哪，左右子树切不开，需要额外信息才能重建。

BFS 层序 · 可行

按层写入、按层重建：第一个是根，之后每两个值依次是下一层节点的左右孩子（'#' 同样占位）。队列驱动，与本页的前序递归互为印证。

边界情况 / Edge cases

空树 → "#"

serialize(None) 直接追加 '#'；deserialize 第一个值就是 '#'，build_tree 立刻返回 None。无需特判。

单节点 → "5,#,#"

值后跟两个空标记，恰好三段；读回时根的两个递归各遇到一个 '#'，左右都挂空。

链树（只有左孩子）

如 3→2→1 全左链：串是 "3,2,1,#,#,#"。前序正确记录每个节点先左后右；此时递归深度 = n，是空间复杂度的最坏情况。

斜链与满树之间

任意形状的树都只需要「值 + 空标记」两类 token：形状信息全部编码在 '#' 的位置里，不需要括号等额外分隔符。

复杂度 / Complexity

Time · O(n)

serialize 中每个节点被访问常数次，共 2n+1 次 append；join 把 2n+1 个短串连起来，累计也是 O(n)。deserialize 每个值只消费一次、建一个节点，O(n)。

Space · O(n)

serialized_list 存 2n+1 个 token，O(n)；递归栈深度 O(h)（链树时 h = n 取到最坏）。输出串本身占 O(n) 是否计入，可与面试官讨论。
