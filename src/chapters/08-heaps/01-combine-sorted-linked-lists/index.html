Combine Sorted Linked Lists · 合并 K 个有序链表

Given k singly linked lists, each sorted in ascending order, combine them into one sorted linked list. Example: 1→6, 1→4→6, 3→7 → 1→1→3→4→6→6→7.给定 k 条升序单链表，把它们合并成一条升序链表。例如 lists = [1→6, 1→4→6, 3→7]，合并结果是 1→1→3→4→6→6→7。

完整 Python 代码

class ListNode:    def __init__(self, val: int, next=None):        self.val = val        self.next = next def combine_sorted_linked_lists(lists: List[ListNode]) -> ListNode:    # Define a custom comparator for 'ListNode', enabling the min-heap    # to prioritize nodes with smaller values.    ListNode.__lt__ = lambda self, other: self.val < other.val    heap = []    # Push the head of each linked list into the heap.    for head in lists:        if head:            heapq.heappush(heap, head)    # Set a dummy node to point to the head of the output linked list.    dummy = ListNode(-1)    # Create a pointer to iterate through the combined linked list as    # we add nodes to it.    curr = dummy    while heap:        # Pop the node with the smallest value from the heap and add it        # to the output linked list.        smallest_node = heapq.heappop(heap)        curr.next = smallest_node        curr = curr.next        # Push the popped node's subsequent node to the heap.        if smallest_node.next:            heapq.heappush(heap, smallest_node.next)    return dummy.next

图中每一行是一个堆元素：圆圈内是该链表当前的候选头（堆里的那个节点），右侧是它后面的节点；min 标记指向当前堆顶。

直觉：先会合并两条链表 / Two-list merge

合并两条有序链表很简单：ptr_1、ptr_2 各指向一条链表的头，每次比较两个头，把较小的接入 output 并前进对应指针；一条走完后，把另一条剩余部分直接接上。

问题在 k 条链表上：每一轮要在 k 个头里找最小，逐个比较是 O(k)，n 个节点总共 O(nk)。瓶颈是“反复取最小”——小顶堆恰好把“取最小”降到 O(log k)。

小顶堆做法 / Min-heap strategy

① 压入 k 个头

先用 ListNode.__lt__ 让堆按 val 比大小，再把 lists 里每条非空链表的头 heapq.heappush 进堆。

② 弹出最小并接入

哑节点 dummy = ListNode(-1) 做占位头，curr 从它开始。每轮 heappop 出最小节点，执行 curr.next = smallest_node，再 curr = curr.next 前移。

③ 后继补回堆

被弹出节点的 next 是同一链表的下一个候选；若非空就压回堆。重复直到堆空，返回 dummy.next。

为什么正确 / Why it works

核心不变量：堆中始终恰好保存每条未耗尽链表的一个候选头。每条链表自身升序，所以候选头就是该链表的最小剩余节点；所有链表的最小值中再取最小（堆顶），必是全局最小。把它接到输出尾部，输出链表保持升序；堆空时所有节点都已接入。

旧 next 不用手动断开

节点接入输出时还带着原来的 .next（例如第一个 1 仍指着 6）。但 curr 前移后，下一轮 curr.next = smallest_node 会直接把这条旧链接改写成新节点，所以无需额外断链。

相等值任取其一

两个 1、两个 6 相等时，堆先弹哪个都行：它们数值相同，接入顺序不同但结果链表完全一样。

边界与细节 / Edge cases

输入含空链表

if head: 会跳过 None，空链表不参与压栈，堆只收集真实头节点。

所有链表为空

堆一直为空，while heap: 直接结束，返回 dummy.next 即 None。

全局修改的提醒

ListNode.__lt__ = ... 修改的是全局的 ListNode 类，会影响程序里所有链表。面试时先确认这种全局改动可以接受；避免的方式是压入 (val, node) 二元组再取出节点。

k = 1 或单节点

只有一条链表时堆大小恒为 1，算法退化为“逐个取出再接上”，依然正确。

复杂度 / Complexity

Time · O(n log k)

建堆时把 k 个头逐个插入，O(k log k)；之后 n 个节点每个各经历一次 push 和一次 pop，各 O(log k)。合计 O(k log k) + n·O(log k) = O(n log k)。

Extra space · O(k)

堆在任何时刻至多保存每条链表的一个候选头，最多 k 个节点；输出链表复用原节点，不额外分配。
