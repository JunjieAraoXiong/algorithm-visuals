Largest Square in a Matrix · 矩阵中的最大正方形

Given a binary matrix, return the area of the largest square made only of 1s.给定一个只含 0 和 1 的矩阵，返回全部由 1 组成的最大正方形的面积。

matrix 输入

dp 最大边长

dp[i][j] 的含义

i, j
matrix[i][j]
dp[i][j]
max_len

Final Python / 最终代码

def largest_square_in_a_matrix(matrix: List[List[int]]) -> int:    if not matrix:        return 0    m, n = len(matrix), len(matrix[0])    dp = [[0] * n for _ in range(m)]    max_len = 0    # 基础情况：第 0 行的 1 只能构成 1×1 正方形    for j in range(n):        if matrix[0][j] == 1:            dp[0][j] = 1            max_len = 1    # 基础情况：第 0 列的 1 只能构成 1×1 正方形    for i in range(m):        if matrix[i][0] == 1:            dp[i][0] = 1            max_len = 1    # 其余格子：边长受上、左、左上三个邻居限制    for i in range(1, m):        for j in range(1, n):            if matrix[i][j] == 1:                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])            max_len = max(max_len, dp[i][j])    return max_len ** 2

右侧 dp 表只存“边长”，面积在最后一行才平方。

Subproblem / 子问题

直接枚举每个正方形太慢。换一个问法：以 (i, j) 为右下角的全 1 正方形，边长最大是多少？把这个值存进 dp[i][j]，答案就是整张表里的最大值的平方。

matrix[i][j] == 0

任何以 0 为右下角的正方形都不全是 1，所以 dp[i][j] = 0（表初始化时已经是 0）。

matrix[i][j] == 1

想扩成边长 k，上方、左方、左上方各自都必须至少撑起边长 k − 1 的正方形。

Why the minimum / 为什么取最小值

三个邻居各自边长 k − 1 的正方形叠在一起，正好覆盖以 (i, j) 为右下角、边长 k 的正方形除了 (i, j) 本身以外的所有格子。只要有一个邻居短，就会留下一个“洞”。

top = 2, left = 2, diag = 1
01111111?

左上邻居只有 1，说明 3×3 的左上角缺了一个 1，所以只能得到 1 + 1 = 2。

top = 2, left = 2, diag = 2
11111111?

三个 2×2 正方形合起来覆盖整个 3×3 的其余部分，得到 1 + 2 = 3。

  1. 按行从上到下、每行从左到右填表，计算 (i, j) 时三个邻居都已经算好。
  2. 第 0 行、第 0 列没有完整的三个邻居，单独作为基础情况：是 1 就是 1。
  3. max_len 记录目前见过的最大边长；返回前平方得到面积。

Edge cases / 边界情况

[]

空矩阵直接返回 0。

[[0, 0], [0, 0]]

没有 1，max_len 保持 0，面积 0。

[[1, 1, 1]]

只有基础情况会执行，内层循环不运行，答案是 1。

空间优化

计算第 i 行只用到第 i − 1 行，所以可以只保留两行，把额外空间降到 O(n)。

Complexity / 复杂度

Time · O(m · n)

每个格子只计算一次，每次 O(1)。

Space · O(m · n)

dp 表与输入同样大小；只保留两行时为 O(n)。
