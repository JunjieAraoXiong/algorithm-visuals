Happy Number · 快乐数

Repeatedly replace a number with the sum of the squares of its digits. Reaching 1 means happy; revisiting a state means the process is trapped in a cycle.反复把数字替换为各位数字的平方和。到达 1 表示快乐数；重复出现某个状态表示进入无限循环。

Final Python / 最终代码

The visual splits the nested fast call into two hops; both map to the same source line. / 动画把嵌套调用拆成两跳，但两帧都对应同一行源码。

def happy_number(n: int) -> bool:    slow = fast = n    while True:        slow = get_next_num(slow)        fast = get_next_num(get_next_num(fast))        if fast == 1:            return True        if fast == slow:            return False def get_next_num(x: int) -> int:    next_num = 0    while x > 0:        digit = x % 10        x //= 10        next_num += digit ** 2    return next_num

Turn arithmetic into a linked path / 把算术过程看成链路

Every integer has exactly one next state, so the sequence forms a functional graph: a path ending at 1, or a path entering a cycle. / 每个整数都只有一个确定的下一状态，因此它形成函数图：要么到达 1，要么进入一个环。

happy path / 快乐路径

Terminate at 1 → True. / 到达 1。

cycle / 无限循环

58 → 89 → 145 → 42 → 20 → 4 → 16 → 37 → 58

A repeated state proves the process will never reach 1. / 重复状态证明以后也不会到达 1。

The two stopping conditions / 两种停止条件

success / 成功

if fast == 1: return True

1 maps to itself, so reaching it proves happiness immediately. / 1 会继续映射到自己，因此可以立即返回。

cycle / 环

if fast == slow: return False

The pointers met at the same number state before reaching 1. / 两者在到达 1 前于同一数字状态相遇。

Solving steps / 解题步骤

  1. Define the next state / 定义下一状态： sum the squares of all digits.
  2. Recognize a functional graph / 识别函数图： each number has exactly one outgoing arrow.
  3. Reuse Floyd / 复用快慢指针： move slow once and fast twice.
  4. Check in order / 按顺序判断： reaching 1 returns True; meeting elsewhere returns False.

Complexity / 复杂度

Time / 时间 · O(log n)

The first digit transform examines O(log n) digits; later states are bounded by their digit-square sum. / 第一次转换检查 O(log n) 个数位，之后状态被数位平方和限制在较小范围。

Extra space / 额外空间 · O(1)

Floyd stores two number states and a few scalar variables. / 只保存两个数字状态和少量标量变量。
