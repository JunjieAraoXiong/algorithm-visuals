Median of an Integer Stream · 整数流的中位数

Design a data structure that supports add(num: int) -> None and get_median() -> float: integers arrive one at a time from a stream, and get_median() returns the median of everything received so far.设计一个数据结构：整数流每次到来一个数 add(num)，随时调用 get_median() 返回目前所有整数的中位数。例：add(3), add(6), get_median() → 4.5, add(1), get_median() → 3.0。

不变量 / Invariant

num
size(left_half)
size(right_half)
max(左) ≤ min(右)
median

完整 Python 代码

import heapq class MedianOfAnIntegerStream:    def __init__(self):        self.left_half = []  # Max-heap.        self.right_half = []  # Min-heap.     def add(self, num: int) -> None:        # If 'num' is less than or equal to the max of 'left_half',        # it belongs to the left half.        if not self.left_half or num <= -self.left_half[0]:            heapq.heappush(self.left_half, -num)            # Rebalance the heaps if the size of the 'left_half'            # exceeds the size of the 'right_half' by more than one.            if len(self.left_half) > len(self.right_half) + 1:                heapq.heappush(self.right_half, -heapq.heappop(self.left_half))        # Otherwise, it belongs to the right half.        else:            heapq.heappush(self.right_half, num)            # Rebalance the heaps if 'right_half' is larger than            # 'left_half'.            if len(self.left_half) < len(self.right_half):                heapq.heappush(self.left_half, -heapq.heappop(self.right_half))     def get_median(self) -> float:        if len(self.left_half) == len(self.right_half):            return (-self.left_half[0] + self.right_half[0]) / 2.0        return -self.left_half[0]

Python 的 heapq 只有小顶堆：left_half 里存的是 -num，最小的负数恰好对应原数中的最大值；读取时用 -left_half[0] 还原。

直觉：中位数住在排序后的中间 / The middle of the sorted values

中位数永远落在「排好序的所有值」的正中间。数据流不会按顺序到达，但我们并不真的需要维护一个完整的有序列表——只需要随时能指出两个值：左半边的最大值和右半边的最小值，中位数由它们直接算出。

  1. 第一个中位值（median value）是排序后左半边的最大值——大顶堆的堆顶恰好能给出它。
  2. 第二个中位值是排序后右半边的最小值——小顶堆的堆顶恰好能给出它。

把数据切成「较小的一半」和「较大的一半」后，中位数只由两半的堆顶决定：总数为偶数时取两个堆顶的平均，为奇数时取左堆顶。这就是上图虚线框里两个值与下方双堆的对应关系。

双堆结构：两条规则 / Two heaps, two rules

left_half 是一棵大顶堆，保存较小的一半，堆顶 = 第一个中位值；right_half 是一棵小顶堆，保存较大的一半，堆顶 = 第二个中位值。任何时刻都要满足：

  1. 值规则：max(left_half) ≤ min(right_half)——左堆的每个值都不超过右堆的每个值，两半拼起来正好是有序的。
  2. 尺寸规则：两堆大小相等；当总数为奇数时，left_half 恰好多 1 个，此时唯一的那个中位数就是左堆顶。
偶数个 · 两个中位值

两堆大小相等，各贡献一个堆顶：(-left_half[0] + right_half[0]) / 2.0。

奇数个 · 中位数在左堆顶

左堆比右堆多 1 个，多出来的那个就是正中间：-left_half[0]。

再平衡：把多出来的堆顶搬过去 / Rebalancing

add 之后尺寸规则可能被破坏，修复方式只有一个：从「多出来」的那一侧弹出堆顶，放进另一侧。搬的是堆顶，所以值规则依然成立——被搬走的总是左半边的最大值或右半边的最小值，搬到对面后仍然夹在中间。

左堆过大：max 搬去右堆

len(left) > len(right) + 1：弹出 left_half 堆顶，取负后推进 right_half。

右堆过大：min 搬去左堆

len(right) > len(left)：弹出 right_half 堆顶，取负后推进 left_half。

实现技巧：用负数伪造大顶堆 / Negated min-heap

Python 的 heapq 只有小顶堆。把每个数取负再放进 left_half：原始值越大，取负后越小，就越靠近小顶堆的堆顶——于是 -left_half[0] 恰好是左半边的最大值。读堆顶时乘回 -1 即还原原值，例如堆里存 -6，读出来是 -(-6) = 6。

存进去 / push

heapq.heappush(self.left_half, -num)：add(6) 时实际存入的是 -6。

读出来 / read

-self.left_half[0]：堆顶是 -6，取负还原为 6，即左半边最大值。

边界情况 / Edge cases

空堆调用 get_median

题目保证至少添加过一个值后才会调用 get_median()，所以 -self.left_half[0] 永远不会访问空堆顶。

第一个值

not self.left_half 让第一个数无条件进左堆；奇数个时中位数一直在元素更多的 left_half。

负数与 0

取负技巧对负数同样成立：add(-5) 存入 5，读取 -5，比较与搬移逻辑完全不变。

重复值

num <= max 时进左堆，相等的值可以落在同侧相邻位置，max(左) ≤ min(右) 依旧成立。

复杂度 / Complexity

add · O(log n)

n 为已添加的元素个数。一次 heappush 是 O(log n)；若需再平衡，一次 heappop 加一次 heappush 也是 O(log n)，合计仍是 O(log n)。

get_median · O(1)

只读取堆顶：偶数时读两个堆顶求平均，奇数时读左堆顶，都是常数时间。

Space · O(n)

两个堆合起来保存全部 n 个元素，没有额外数据结构。

一句提醒 / Note

文中把中间的两个值叫作「median values」只是方便说法：中位数永远只有一个，它们只是用来计算中位数的两个中间值。
