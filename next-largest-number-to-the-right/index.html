Next Largest Number to the Right · 右侧下一个更大数

Given an integer array nums, return an array res where res[i] is the first number to the right of nums[i] that is larger than nums[i]. If no larger number exists to the right, set res[i] to -1.给定整数数组 nums，返回 res：res[i] 是 nums[i] 右侧第一个比它大的数；右边没有更大的数时 res[i] = -1。

不变量 / Invariant

nums[i]

完整 Python 代码

def next_largest_number_to_the_right(nums: List[int]) -> List[int]:    res = [0] * len(nums)    stack = []    # Find the next largest number of each element, starting with the    # rightmost element.    for i in range(len(nums) - 1, -1, -1):        # Pop values from the top of the stack until the current        # value's next largest number is at the top.        while stack and stack[-1] <= nums[i]:            stack.pop()        # Record the current value's next largest number, which is at        # the top of the stack. If the stack is empty, record -1.        res[i] = stack[-1] if stack else -1        stack.append(nums[i])    return res

栈底在左、栈顶在右；stack[-1] 是最近加入的候选。

例子与暴力做法 / Example and brute force

暴力做法：每个 nums[i] 都向右线性扫一遍，找第一个更大的数，最坏 O(n²)。虚线箭头表示“右侧第一个更大的数”：5 → 6、2 → 4、4 → 6，而 6 和 1 右边没有更大的数，记 -1。

换个视角：谁是它的“客户” / Invert the question

不要问“每个数右边第一个更大的是谁”，改问：这个数会成为它左边哪些数的答案？看上面的例子：6 正是 5 和 4 的答案。于是把数组从右往左扫描——处理一个数时，它右边的数都已经见过了，其中“还可能当上答案”的数称为候选（candidates）。越靠右的候选离当前数越近，所以最新的候选（最右边那个）优先：它就是答案，除非有更小或相等的候选挡在中间需要剔除。

关键观察：候选严格递减 / Monotonic stack

新数 x 到来时，候选里所有 ≤ x 的数都可以删除：以图中的 2 为例，3 比它大、又比它更靠左——任何将来“以 2 为答案”的数，离它更近、更大的 3 总是更优。删除只会发生在候选列表末尾，压入也只发生在末尾：这正是栈。删除后压入 x，栈里的值自栈底向栈顶严格递减，栈顶永远是最近的候选。

第 1 步 · 弹出不行的候选

while stack and stack[-1] <= nums[i]：栈顶小于或等于当前值就 stack.pop()，这些候选再也不可能成为答案。

第 2 步 · 栈顶即答案

剩下的栈顶是最近的、比当前值大的候选：res[i] = stack[-1]；若栈空，右边没有更大的数，记 -1。

第 3 步 · 当前值入栈

stack.append(nums[i])：当前值自己也可能成为左边某些数的答案，压入栈顶成为新候选。

为什么栈顶是“最近”的

栈底到栈顶严格递减，且靠右的数先入栈——栈顶就是离当前值最近的候选；答案要求“第一个”（最近），所以只需看栈顶。

边界情况 / Edge cases

相等的值

条件用 <=，相等的候选也会被弹出：答案必须严格更大。nums = [3, 3] 时第二个 3 入栈后，第一个 3 的候选里只剩…栈顶是 3，3 <= 3 成立被弹空，res = [-1, -1]。

严格递减数组

[4, 3, 2, 1]：没有任何候选会被弹出，栈一路长到 n，res 全是 -1——最坏情况，空间 O(n)。

递增数组

[1, 2, 3, 4]：每个新值都弹空栈，res = [2, 3, 4, -1]，栈里始终只留一个最大值。

只有一个元素

循环只跑一趟：栈空，res = [-1]。

复杂度 / Complexity

Time · O(n)

每个值最多 append 一次、pop 一次；所有弹出的总数不超过 n。虽然里面有 while 循环，总代价仍是 O(n)。

Extra space · O(n)

栈最坏存下所有值（严格递减输入时），即 O(n)。
