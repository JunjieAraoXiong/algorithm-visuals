Evaluate Expression · 表达式求值

Given a string s representing a mathematical expression containing integers, parentheses, and '+' / '-' operators, evaluate and return the result. For example, s = "18-(7+(2-4))" returns 13.给定一个只包含非负整数、加减运算符和括号的字符串表达式，求它的值。表达式里没有乘除，也没有空格。

不变量 / Invariant

curr_num
sign
res
stack（右端栈顶）

完整 Python 代码

def evaluate_expression(s: str) -> int:    stack = []    curr_num, sign, res = 0, 1, 0    for c in s:        if c.isdigit():            curr_num = curr_num * 10 + int(c)        # If the current character is an operator, add 'curr_num' to        # the result after multiplying it by its sign.        elif c == '+' or c == '-':            res += curr_num * sign            # Update the sign and reset 'curr_num'.            sign = -1 if c == '-' else 1            curr_num = 0        # If the current character is an opening parenthesis, a new        # nested expression is starting.        elif c == '(':            # Save the current 'res' and 'sign' values by pushing them            # onto the stack, then reset their values to start            # calculating the new nested expression.            stack.append(res)            stack.append(sign)            res, sign = 0, 1        # If the current character is a closing parenthesis, a nested        # expression has ended.        elif c == ')':            # Finalize the result of the current nested expression.            res += sign * curr_num            # Apply the sign of the current nested expression's result            # before adding this result to the result of the outer            # expression.            res *= stack.pop()            res += stack.pop()            curr_num = 0     # Finalize the result of the overall expression.    return res + curr_num * sign

直觉：把减法变成加法 / Signs turn everything into addition

表达式里只有非负整数、'+'、'-' 和括号。给每个数配上一个符号 sign（'+' 记为 1，'-' 记为 -1），那么 curr_num * sign 就把减法变成了加法——res 从头到尾只做累加。

多位数不能逐位直接算，用 curr_num 一位一位构建：curr_num = curr_num * 10 + int(c)，相当于把已有数字左移一位再补上新的数字位。遇到运算符或括号这种非数字字符，就说明当前数读完了。

没有括号 · 28 - 10 + 7res：0 → 28 → 18 → 25

遇到 '-' 时把已读完的 28 按符号 +1 加进 res，再把 sign 换成 -1、curr_num 归零；字符串结尾还要把最后的 7 加进去。

同一套规则处理每个字符digit / op / '(' / ')' 四类分支

数字扩展 curr_num；运算符收尾当前数并更新 sign；'(' 与 ')' 借助栈保存和恢复外层状态。

括号与栈：先算内层 / Nested expressions

'(' 开始一段新的嵌套表达式。先把外层进度保存起来——stack.append(res) 再 stack.append(sign)，栈里从底到顶是「外层的 res，括号前的 sign」；然后 res, sign = 0, 1，用同一套规则计算括号内部。

')' 结束嵌套表达式：先 res += sign * curr_num 把括号内的最后一个数收尾，得到内层结果；res *= stack.pop() 弹出括号前的符号乘上去；res += stack.pop() 把外层累计值加回来。有几层括号就重复几次。

18-(7+(2 - 4))solve · 最内层 (2 - 4) = -2
↓18-(7 - 2)solve · (7 - 2) = 5
↓18 - 5= 13solve · 整个表达式的值

弹出顺序和压入顺序相反：后压入的 sign 先弹出，所以先乘符号、再加外层结果。栈先保存 res 再保存 sign，正好让 sign 位于栈顶。

边界情况 / Edge cases

多位数

读 "123" 时 curr_num 依次是 1 → 12 → 123；数字结束于下一个非数字字符，不需要提前知道位数。

内层结果为负

(2 - 4) = -2。负号由 sign 保存在 res 里，')' 时乘的是括号前的符号（本例为 1），负数无需特殊处理。

结尾没有运算符

最后一个数之后可能直接是字符串结尾或 ')'。结尾靠 return res + curr_num * sign 收尾；遇到 ')' 则靠 res += sign * curr_num 收尾。

嵌套很深

每遇到一层 '(' 压入两个值，栈的深度与括号层数成正比，最坏 O(n)。

复杂度 / Complexity

Time · O(n)

每个字符只访问一次；栈的 append 和 pop 都是 O(1)。n 是表达式 s 的长度。

Extra space · O(n)

每层嵌套括号在栈中保存 res 和 sign 两个值，最坏情况下栈随表达式长度线性增长。
