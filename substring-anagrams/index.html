Substring Anagrams · 字母异位子串

Count the length-len(t) substrings of s whose character frequencies exactly match t. The order may differ; the counts may not.统计 s 中长度为 len(t)、且字符频率与 t 完全相同的子串。顺序可以不同，次数必须相同。

Final Python / 最终代码

def substring_anagrams(s: str, t: str) -> int:    len_s, len_t = len(s), len(t)    if len_t > len_s:        return 0     count = 0    expected_freqs, window_freqs = [0] * 26, [0] * 26    for c in t:        expected_freqs[ord(c) - ord('a')] += 1     left = right = 0    while right < len_s:        window_freqs[ord(s[right]) - ord('a')] += 1        if right - left + 1 == len_t:            if window_freqs == expected_freqs:                count += 1            window_freqs[ord(s[left]) - ord('a')] -= 1            left += 1        right += 1     return count

window_freqs == expected_freqs is constant time here because both arrays always contain exactly 26 entries. / 两个数组始终只有 26 项，因此比较可视为常数时间。

Why the window is fixed at three / 为什么窗口长度固定为三

An anagram must use every character of t = "aba" exactly once, so only length-three substrings can qualify. The window enumerates all four candidates without rebuilding them. / 异位词必须恰好使用 t 的全部字符，因此只需检查长度为三的子串。

Frequency arrays / 频率数组

ord(character) - ord('a') converts a lowercase letter into an array index.

a0b1c2…z25

Order is discarded; frequency remains. "aab" and "aba" both become {a:2, b:1}. / 顺序被忽略，出现次数被保留。

Complexity / 复杂度

Time / 时间 · O(n)

Populate t once, then move each window boundary across s once. / 先统计一次 t，再让窗口线性经过 s。

Extra space / 额外空间 · O(1)

Two fixed arrays of 26 integers. / 两个固定长度为 26 的数组。
